# 无界笔记文档视图与课程关系

- 状态：已接受并实施。当前状态及验收范围见[无界笔记设计 §0](../设计/无界笔记.md#0-状态分层)。
- 延续 [ADR-0015](0015-无界笔记模块与独立数据域.md) 的单入口、[ADR-0016](0016-无界笔记持久化与单文件版本栅栏.md) 的独立存储与版本栅栏、[ADR-0017](0017-学习节点笔记与共享即时编辑.md) 的课程身份和同一保存者。本决定补充后者的交互，并修订 [ADR-0018](0018-共享Markdown局部编辑与格式栏.md) 的独立文档视图范围。[ADR-0019](0019-无界笔记懒分块加载.md) 的按需加载不变。

## 背景与决定

快速编辑侧栏与独立文档承担不同空间和任务：侧栏需要就地编辑，独立文档需要源码、预览和并排阅读。为此只在独立文档提供多种视图，侧栏继续局部渲染编辑；它们仍共用原稿和保存者，不以视图切换改写正文。本文补充而非推翻 ADR-0018 的原 Markdown 编辑模型。

离开「学习」后重进时，在同一标签、同一工作区恢复界面位置与逐篇文档模式；界面状态不进入笔记数据域，也不承诺跨刷新、关标签、跨项目或跨设备恢复。恢复范围见[工作空间](../设计/无界笔记.md#22-工作空间)，模式、窄屏行为和编辑语义见 [Markdown 编辑与外部来源](../设计/无界笔记.md#7-markdown-编辑与外部来源)，外观判据归[阅读端呈现](../规范/阅读端呈现.md) §九。

## 本的绑定、笔记的关联、原件的归属

本级绑定、单篇课程关联与原件归属是三种不同关系：更换默认本不迁移旧稿，解除绑定不删除单篇关联，节点间分类不移动原件。为避免误替换已有分类，同科目从一个节点更换到另一个节点须确认。具体规则归[无界笔记设计 §3–§5](../设计/无界笔记.md#3-资源树与科目绑定)。

## 资源操作

已有资源拖上画布只建立引用；复制 Markdown 改为显式操作，产生独立身份。外部文件导入仍需选择副本或引用。这收窄了早期对所有画布拖拽都要求选择的表述，避免把引用误当成复制。资源操作和改名后的类型处理统一见[无界笔记设计 §6.2](../设计/无界笔记.md#62-卡片与连接)。

## 验收

真实 Edge 使用临时笔记库和宿主夹具，实际卸载并重挂 React 根，核对文档模式、位置和在途草稿恢复。夹具加载正式入口及其懒分块，不连接正在运行的 DSH 实例，不读取用户笔记。运行入口及测试边界见[测试说明](../../scripts/tests/README.md#浏览器套件与手动工具)。
