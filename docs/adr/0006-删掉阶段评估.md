# 删掉阶段评估

**每 3–5 个节点一次的阶段评估删除。** 实验课验收保留，仍由出题角色做，结论写进学习记录。

## Considered Options

- **保留但减负**：只删节拍、保留结论产物。省事，但"谁判断学生真的会了"这个问题仍然悬着，且评估记录与学习记录两套产物并存。
- **连实验课验收一起删**：最彻底，但"造出"这一层的交付物到底好不好用，机器测不出来。

## Consequences

- `assessments/` 目录与评估记录 schema 退役；验收结论改写进学习记录。
- 出题角色的职责从"出题 + 判分 + 评估"收窄为"出题 + 实验课验收"。
- 普通节点的进度推进改为"学生自评 + 作答历史 + 机器事实"，不再有第三方判断——这意味着进度三档里的"已学完"在普通节点上是**自评驱动**的，只有实验课节点有外部验收。这是本决策最可能被质疑的一处。
- "考考我"这个用法消失；学生想检验自己，只能通过实验课任务与页内自测。
