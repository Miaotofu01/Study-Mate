# 顶栏收起是手动开关，不跟滚动走

阅读端顶栏是一条常驻的横条，放品牌、面包屑、搜索与两个阅读偏好。它占的是高度：窄画布下还会折成两三行，正文能开始的那条线被顶得更低。这次给它一个**显式**的收起开关——右侧一枚图标按钮，点了收成一条 14px 的细条，再点（或点细条本身）展开；不做任何自动行为。

收起态**不归零**：细条本身就是那个开关，恢复入口永远在眼前。按钮在收起前后是**同一个元素**，`aria-expanded` 与 `aria-label` 跟着翻，`aria-controls` 指向的顶栏 id 也一直在——所以焦点不会因为换节点而丢。状态记在浏览器本地偏好里（与字号、动效同级），默认展开；宿主内刷新与导出的离线页都保持，`localStorage` 不可用时退化为展开、不报错。

窄画布下顶栏**恒为一行**：不再让品牌 + 面包屑 + 搜索 + 开关折成两三行。面包屑照旧按全角字省略，字号与动效两个阅读偏好控件在这一档不出现（它们的入口只在宽档顶栏里；这是拿「窄屏先把空间给导航与正文」换掉的，不是把它们删了）。

## Considered Options

- **滚动自动隐藏（向下滚收起、向上滚展开）**：省掉一次点击，但这一页有**两个滚动容器**（`.smb-scroll` 与课件页的 `.smb-center__body`），而且顶栏是 `flex: none` 的直接兄弟：收起它会改内容高度，滚动位置跟着跳。要藏得干净只能改成覆盖层再加 padding 补偿，还得给按渲染尺寸算栏宽的 `planPanes` 加一个「顶栏高度」变量——为了省一次点击，把测量、定位、滚动三条链路都拖进来。否掉。
- **收起到 0 高度，把展开按钮浮在正文右上角**：最省空间，但浮层会压在窄屏的文字上；而且「恢复入口在哪」变成要记的事。留 14px 细条把入口固定在它原来待的位置。否掉。
- **顺手做「阅读模式」（收起顶栏并收两侧窄轨）**：那是另一件事。两侧窄轨的宽度与让位顺序归 [ADR-0011](0011-阅读端三栏让位顺序.md)（空间预算：右 640 / 左 460 / 中保底 420 / 窄轨 38），顶栏是沉浸偏好——两套逻辑混在一起，谁改谁都会踩到对方的不变量。这次只动顶栏。否掉。
- **空闲计时自动收起**：与滚动自动隐藏同一类问题（页面在没人操作时自己变），还多一个「多久算空闲」的魔法数，否掉。

## Consequences

- **收起的代价是导航暂时消失**：品牌按钮（回主页）与面包屑都不在细条里，只剩「展开顶栏」这一条。这是接受的取舍——要看位置就点一下展开；搜索不受影响，⌘K 是独立入口。
- **14px 低于常用的 44pt 触控目标**：不靠加高度补（那会把刚省下来的空间吃回去），补的是**全宽点击区**——收起态整条细条都是按钮，点哪都展开。
- **顶栏的收起/展开状态**是浏览器本地偏好，不写学习工作区，也不改变任何学习数据；换浏览器或清掉站点数据就回到默认展开。
- **窄档的阅读偏好入口只剩宽档**：字号、动效两个控件在 `max-width: 900px` 下不渲染。这是「顶栏恒一行」的直接后果，别把它当成两个功能的退役——宽档里它们照旧。
- **导出页自动获得同一行为**：导出只搬 `lib/client.js` 这一份渲染代码，壳（`lib/export/page.ts` 与导出页的 `index.html`）不加任何覆盖样式。两侧的哈希门禁盯着「产物里的 client.js 与仓库逐字节相同」，正是这条保证的来源。
- **`file://` 下 `localStorage` 可能抛错**：读与写都在 try/catch 里，读失败按默认展开、写失败只是不持久化；手动开关仍然可用。这条由导出页的真浏览器套件钉住。
