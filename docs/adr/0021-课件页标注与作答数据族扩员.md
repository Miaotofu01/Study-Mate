# 课件页标注：高亮、侧注、落盘与引用提问（作答数据族扩员）

> 编号：本 ADR 最初落地时占 0015，与同批落地的《无界笔记》ADR（`0015-无界笔记模块与独立数据域.md`）撞号；2026-11-17 改为 0021，正文内容未变。

阅读端课件页允许学生对正文划选：选中一段 → **高亮 + 写一条注释**；一条标注可以跨块（学生从一段划到下一段是常态）。
标注写进学习工作区 `<subject_path>/annotations/<NNNN>-<节点id>.json`，与课件一一对应——刷新、重开、换一台机器都在。
学生可以多选一条或几条标注，作为**引用 chip** 送进答疑会话；导出产物内嵌同一份标注的**只读快照**。

定位不存裸字符偏移：一条标注 = `{id, note, ranges, created, modified}`，每个 range 是
`{line, kind, hash, start, end}`——**行号 + 块类型 + 块文本指纹 + 块内字符区间**。块切分只由阅读端的
`parseBlocks` 说了算：Host 半写入时不重新解析课件、读回也不解析，只做字节存储与版本栅栏。课件被重写后，
对不上的标注按仓库已有的四态（`resolved` / `stale` / `ambiguous` / `missing`）显式报出来，**不静默贴到错误位置**；
「重新指定到当前段落」由学生手动点，第一版不做相似度自动重定位。

这是 [#225](https://github.com/Miaotofu01/Study-Mate/issues/225) 的 ③、[#111](https://github.com/Miaotofu01/Study-Mate/issues/111)
的设计方向；与 #110 / #122 三张票的关系见 PR 描述。

## 与 ADR-0004：新增，不是改动

[ADR-0004](0004-学习数据格式冻结与例外.md) 冻结学习工作区的布局、文件名与目录结构。本条新增两样东西：
科目目录下一个 `annotations/` 子目录、一份 `schemas/annotations.schema.json`。边界写死：

- **动的**：只新增。`annotations/` 是科目目录里新的一级子目录；`annotations.schema.json` 是新的一份 schema。
- **不动的**：任何已有文件的名字与内容、已有目录结构、已有 schema、`templates/` 的既有骨架。
  旧工作区没有 `annotations/` 照样能开：读侧按需存在（`present:false`），第一次标注才创建目录。
- **零迁移**：没有重命名、没有内容转换、没有迁移命令。

[ADR-0014](0014-共享记忆改名MEMORY.yaml.md) 是一模一样的先例：它新增科目 `MEMORY.yaml` 时也破了 ADR-0004，
但破法是「新增而非改动」，所以「旧工作区零迁移」原样成立。本条沿用这个先例，并把 ADR-0014 里
「五份 schema 不动」那句收窄成**已有 schema 不动**——新增 schema 属于 ADR-0004 冻结的例外；
本 ADR 是这个例外的边界，不是新的冻结。

## 与 ADR-0010：不是第三条路径，是作答数据这一族的扩员

[ADR-0010](0010-阅读端可直接写参考资料.md) 写明：阅读端直接写学习内容是「作答数据之外的**第二条、也是最后一条**路径」。
标注**不是第三条**——它和 `attempts/` 是同一族：

- 同为学生对内容的反应，不是模型写的课件内容；
- 同为派生记录：删掉标注不损失任何学习内容，课件、题库、大纲、进度都不依赖它；
- 模型直接可读：一份普通 JSON 文件，第一版不需要契约、不需要提示词改动；
- 不碰人机共写的课件内容：`lessons/*.md` 与 `*.quiz.json` 一个字节都不改。

于是它落在 ADR-0010 已经批准的那一侧：「学习内容由总控与阅读端分别写入，各自范围不重叠」——
阅读端能碰 `reference/` 与**作答数据族**（`attempts/`、`annotations/`），课件、题库、进度、大纲仍只由模型与工具写。
ADR-0010 的「最后一条」指的是**新的写入路径**；给已批准的那一族加一个文件不是新路径。
边界同样写死：标注只增删自己目录里的文件，不写回 `.md` / `.quiz.json`，不进进度与大纲。

## Considered Options

- **浏览器 localStorage**：最省事，也能跨刷新。但清一次浏览器缓存就丢、换一台机器没有、模型永远读不到——
  「换机器还在」「模型可直接读」两条硬需求同时落空。静态页时代试过并放弃（导出的静态页里本地标注只能自己看，
  回不到学习数据里）。
- **放进笔记数据域 `<DSH_HOME>/studymate-notes/`**：笔记域已经有「科目 + 节点」这层关联，看着能复用。
  但它的关联键只有 workspace + 科目 + 节点，**没有「课内段落」这一级**：要存块锚点就得在笔记域里再造一套
  文件布局与 schema，等于两个数据域各写一遍同一件事；而且笔记与课件分居两处，课件重写时两边没法一起对账。
- **写回课件 `.md`**（把高亮直接写进正文）：文件最少，但课件是模型写的、下次重写会整段覆盖；
  ADR-0007 已经把「作答不写回题库」的理由写死，同一份理由对课件正文一样成立。
- **只存原文或只存裸字符偏移**：存原文没法还原位置；存裸偏移在正文改一个标点后就整体串位。
  行号 + 块指纹 + 块内区间是两者的组合：改动只影响真正改了的那一块。
- **相似度自动重定位**：能省掉学生点一下，但误贴的代价远高于失效标签——学生会对着一段没标过的文字看到自己的注释。
  第一版宁可显式报失效。
- **最右边栏边注**：正文列是 `clamp(760px, 66%, 900px)`，右栏本来就紧张、还可以折叠；窄画布没有余量。
  第一版用行内小标记 + popover，不占栏。

## Consequences

- **Host 半不解析课件**：块切分只由客户端 `parseBlocks` 说了算（它与服务端 `lib/core/format.ts` 是两份独立实现，
  客户端更宽松）。Host 写入、读回都只做字节存储 + 版本栅栏，双解析器漂移不会渗进数据层。代价是 Host 无法校验
  range 指向的块是否真实存在——那是客户端渲染时的对账职责，不是写入前的判据。
- **写入沿用现成的两件武器**（ADR-0007 与 `lib/core/fence.ts`）：`operationId` 幂等重放、`expectedVersion`
  冲突拒绝并重读；每个数据域各持一份幂等台账实例；路径越界拒绝。
- **失效是可见的**：`state !== 'resolved'` 的标注在列表里点名（stale 显示「这条标注的原文已变」），不自动改位置；
  学生点「重新指定到当前段落」才重绑。四态词表不新增词。
- **导出产物内嵌只读快照**：`lib/export/` 的快照里带 `node.annotations`，离线页仍用同一份 `lib/client.js` 渲染
  （ADR-0005 要求产物自包含、且与阅读端共用同一套解析与渲染规则）——不出现第二个渲染器；离线页没有 Host 写通道，
  标注只读。
- **旧工作区零迁移**：没有 `annotations/` 就是「还没有标注」。读侧给 `present:false`，前端照没有标注渲染。
- **明确不做**：跨课检索、纳入误解库、把标注写回 `.md` / `.quiz.json`、改任何 SKILL / 提示词（第一版只保证
  数据作为普通文件可读）；**废弃 [#122](https://github.com/Miaotofu01/Study-Mate/issues/122) 的「File System Access
  直写工作区」**——阅读端现在有 Host 写盘通道，两条都做必然两套真相。
- **与 #110 的关系**：#110 的静态页已随 ADR-0005 退役；这次导出产物里的只读快照是导出路径，不是阅读端写路径。
