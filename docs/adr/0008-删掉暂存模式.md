# 删掉暂存模式

删除"先在会话目录下的暂存区把课程建完、收尾问学生落点、再 `cp -a` 搬过去"的整套机制。**学习数据直接写进配置里的学习工作区。**

暂存模式存在的唯一理由是 agent 沙箱的可写集只有会话启动目录，而学习工作区可能在别处。写盘改由插件 Host 半完成后，这个前提消失。

## Consequences

- 开场的"定工作区根"一步、收尾的落点问答、`cp -a` 搬运、落点偏好文件全部删除。
- 技能里的临时目录禁忌、跨工具接力约束、暂存区与工作区根的关系全部作废。**产物交接用的 `.stage/` 保留**——它服务的是产物门禁，不是权限。
- 学生不再每次收尾被问一遍"成品放哪"。
- 代价：写盘权限从 agent 转到插件，插件成为唯一写入口，必须自己保证不写坏（见 [ADR-0004](0004-学习数据格式冻结与例外.md) 的映射与测试要求）。
