# 桌面端自研外壳，经 ACP 通道驱动宿主

Status: proposed（2026-10-02 设计会话）

桌面端要长得像 Codex（左科目树、中对话、右课件），但宿主 DSH 的第三方扩展点只能往 slot 里塞组件——三栏 AppFrame 锚在 `'root'`，换不了壳；它的客户端组件是 React，且**没有稳定性承诺**（`dsh-client-runtime` 在 RC 之间消失过，`dsh.engines.dsh` 不匹配即静默禁用整行）。因此桌面端**自研 Vue 外壳**（Naive UI），对话走 **`dsh --profile acp` 的 stdio JSON-RPC（ACP v1）**，不注入 DSH 自己的前端，也不碰无文档的内部 `/api`。

选 ACP 是因为三条官方非 GUI 通道里**只有它保留交互式审批**（`session/request_permission`，allow/reject-once）：`sdk` 通道结构性没有 server→client 请求（"a dead capability"），`headless` 无人应答即 fail-closed 拒绝执行。ACP 同时给出 `agent_message_chunk` / `agent_thought_chunk` / `tool_call` / `tool_call_update` / `usage_update`，以及 `session/new`（可指定工作目录）、`session/list`、`session/resume`、`session/close`、`session/set_config_option`（模型与推理档）。

## Considered Options

- **复用 DSH 整个前端**：最省，第一天就能跑，但外观就是 DSH 自己的样子，做不到 Codex 三栏。
- **自己拼装 DSH 的 React 客户端包**：能同时拿到外观与现成对话 UI，代价是无文档、无稳定性承诺，且要在一个应用里混装两套框架。
- **直接对接 `/api` + `/api/remote.mux`**：流式是 WebSocket，但 wire 只有内部 README、无对外文档、无版本号。
- **`sdk` 通道**：事件最全（61 种，含 `todo/write`、`plan/mode`、子代理），但没有任何审批往返，越界操作只能失败或全放开。
- **`headless`**：只能跑一次性任务，无多轮、无审批。

## Consequences

- **计划、待办、子代理事件拿不到**：ACP 只转发 6 种 update，DSH 专属呈现被 automation-only 排除。桌面端自行 tail 会话记录补出任务侧栏——把 profile 里 `session-persistence-jsonl` 的 `compression` 设为 `none`，就得到逐行 append 的明文 JSONL（整个 root 只能一种编码，桌面端用独立 DSH_HOME，互不影响）。已实测记录里能拿到父会话的 `subagent/catalog{childId,mode,label}`、子会话头 `{parentSession,origin:"subagent",delegationDepth}` 与 `subagent/descriptor`；代价是把任务侧栏钉在记录格式上，上游一次格式迁移就会让它失效。
- **审批请求只带关联 id**：`session/request_permission` 只有 `sessionId` + `toolCallId` + 两个选项（allow-once / reject-once），没有工具名与命令原文，界面必须自己回关联之前的 `tool_call` 通知；`allow-once` 严格一次性，协议里没有「本会话内允许」。拒绝的语义是「这一步被否、整轮继续」，不是任务失败。
- **两个宿主工具在 ACP 会话里不存在**：`ask_user_question` 与 `present` 不在工具表里（原因未定位），而学习技能有三处依赖它们——方向探索的卡片式提问、暂存收尾问成品放哪、呈上页面。桌面端要自带一套替代交互。
- **权限档不能按会话切**：ACP 无此参数，只能在启动进程时用 `DSH_PERMISSION_MODE` 或 profile patch 决定，所以「权限芯片」改档要重起宿主进程。
- **`session/list` 只回 `sessionId` 与 `cwd`**：左栏的会话列表读 `~/.dsh/storages/session_projcache/sessions/*.json`（`identity.cwd`、`sessionListMetadata.lastPromptAt`、`turnOutline.turns[0].prompt`）。
- ACP 在 DSH 侧标注为 automation-only，且官方通道**都没有**版本协商；DSH 锁版本随应用升级（见 [ADR-0002](0002-自带运行时与独立配置目录.md)）。
