# 阅读端可直接写参考资料

阅读端可以把学生自己添加的参考资料直接写进科目的 `reference/`，不再要求经总控转述落盘。这是作答数据之外的**第二条、也是最后一条**阅读端写学习内容的路径。

## Considered Options

- **走总控**：界面只发起，学生在会话里确认一句，写盘归总控。保住"总控是唯一写入者"，但学生加一份自己手上的讲义要绕一圈对话——而总控在这件事上只是转述，没有判断可做。
- **只读**：资料仍由资料收集角色收。最安全，但学生自己的讲义、笔记、真题就进不来，而"带着指定教材自学"是这个产品的核心用法之一。

## Consequences

- 「总控是唯一写入者」改为「**学习内容由总控与阅读端分别写入，各自范围不重叠**」：阅读端只能碰 `reference/` 与作答数据。
- `reference/` 变成人机共写的目录，必须留**来源标记**，否则日后分不清哪份是模型产物、哪份是人放的。
- 需要并发保护（版本号冲突拒绝）与路径越界拒绝。
- 模型重写课件不碰 `reference/`，所以两条写入路径不会互相覆盖——这是范围能切开的前提。
- **本决策最容易被事后质疑的一处**：它开了先例。下一个想从界面直接改进度、改大纲的人会拿它当依据；答案是不行，因为那两处的写入需要判断，而 `reference/` 不需要。
