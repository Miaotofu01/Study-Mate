# 静态页面降为导出

静态 HTML **不再是默认交付**，改为按需导出；阅读端才是主体验。DSH 里学生要时才导，Antigravity 与 Codex 侧默认导出。

## Considered Options

- **双轨长期并存**（Python 渲染器与阅读端都在）：双渲染漂移，两套都得改，学生还会看到两个不一致的版本。
- **彻底删除，连导出也不留**：非 DSH 宿主的学生将无从阅读，而仓库仍宣称支持三宿主。

## Consequences

- 导出产物必须自包含、且不引用任何只存在于 Node 的东西；构建期加一道泄漏守卫。
- `file://` 打开仍然可用，但不再是主路径；README 的演示入口要改。
- 导出与阅读端共用同一套解析与渲染规则，避免出现第二个真相。
