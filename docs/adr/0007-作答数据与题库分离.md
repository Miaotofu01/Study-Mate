# 作答数据与题库分离

作答历史、错因与上次结果写进**独立的作答数据文件**，不写回课件题库。题库保持纯净：仍由模型写、仍与正文锚点逐字对应。

## Considered Options

- **就地写回题库文件**：文件最少，但题库会变成模型与阅读端共写的文件，两边随时撞车——而锚点对账依赖题库的逐字内容。
- **作答完全不落盘**：最轻，但"上次你选了 B"这类就地回顾做不了，也不会有任何可回看的作答证据。

## Consequences

- 每个课件对应一份作答数据，编号与课件一一对应。
- 写入需要幂等与版本号冲突拒绝：并发来自"学生答题"与"模型重出题"两侧。
- 作答数据是派生记录，删掉不影响任何学习内容。
