# 无界笔记：独立持久化、单文件版本栅栏与网页内存态

- 状态：已实施，并通过浏览器回归与默认门禁；状态细节以[无界笔记设计 §0](../设计/无界笔记.md#0-状态分层)为准。
- 范围：[issue #268](https://github.com/Miaotofu01/Study-Mate/issues/268)。
- 前置：[ADR-0015](0015-无界笔记模块与独立数据域.md)。共享源码、单客户端入口、学习内双面切换不变；本决定只补首轮持久化，不扩大成全部多笔记本、归属交接或回收站。
- 接续：[ADR-0017](0017-学习节点笔记与共享即时编辑.md) 增加课程关联、各本画布分区、共享即时编辑与格式 2 显式升级；本文中的格式 1 与单画布结构保留为首轮历史决定。

## 背景

正式 DSH 需要可恢复的笔记与画布，独立网页仍是无宿主、无模型的内存态验收入口。若将正文和画布放进同一份大快照，拖卡片就可能覆盖另一窗口的旧正文；进程内队列又无法协调多个 profile 的 Host 进程。

## 决定

### 1. 独立数据域由宿主的 home 定位

使用 `profileContext.home`，不使用 `profile.dir`、会话 cwd、学习工作区或安装目录。不同 profile 使用同一 DSH 根时共享这份笔记数据。路径和写方登记在[文件归属](../规范/文件归属.md)。

以下目录示意是**首轮格式 1 与单画布的历史形状**；现行格式 2 及其显式升级见 [ADR-0017](0017-学习节点笔记与共享即时编辑.md)，不要把本图的版本号和单画布当作当前格式。

```text
<DSH_HOME>/studymate-notes/
├── _format.json                 # format=studymate-notes，version=1
├── resources/
│   ├── r-<resource-id>.md        # 自有 Markdown 笔记
│   └── r-<resource-id>.json      # 其它资源及外部引用元信息
├── layout.json                  # 单画布、逻辑文件夹及 viewport
└── notes.lock.db                # 仅用于跨进程锁，不存笔记内容
```

未知或损坏格式拒绝写入，不重置、不自动迁移。首次进入可初始化空数据域，但不将演示或旧浏览器内存自动变成正式资料。卸载插件不删除这份用户数据。

### 2. 一个资源一份权威文件

自有笔记是可独立打开的真实 Markdown。文件只在开头附一段命名元信息，之后原样保存用户正文：

```text
---
studymate_notes: <一行 JSON 元信息>
---
<原 Markdown 正文>
```

只解析开头三行，正文自己的 `---` 不参与切分。头部不保存正文副本；标题、逻辑父目录和正文可一次原子替换。文件名由稳定 ID 派生，不随标题或目录名搬动。

其它资源使用 JSON。外部文件引用即使类型是 `note`，也使用 JSON 元信息，不保存缓存正文、File、句柄或权限。重载后必须提示重新选择原文件，不能从路径自行恢复授权。独立副本分配新 ID；已落盘资源不在同一 ID 下切换 Markdown/JSON 物理类型，以免引入两文件事务。

### 3. 布局与资源独立提交

布局保存文件夹、节点、关系和相机。正文卡片只引用 `contentId`；纯文字节点的文字属于节点本身。布局中没有资源正文、媒体副本、聊天草稿或会话 ID，拖动和折叠不写笔记文件。

每个资源文件与布局各有版本：实际完整文件字节的 SHA256，不存在为 `null`。提交必须给预期版本；不符返回冲突及当前值，不覆盖。目标字节相同可幂等成功，供丢失回包后的安全重试。外部编辑器改动也以实际字节检查，而不是只信元信息中的旧 hash。

### 4. OS 锁与单文件原子发布分工

Node 内置 `node:sqlite` 的 `BEGIN IMMEDIATE` 协调短同步临界区。Node 版本范围沿用根包的 `engines`。数据库仅提供跨进程互斥，不保存笔记；不新增 npm 运行时依赖。锁等待有界，操作结束关闭句柄，进程退出由操作系统放锁，不用 PID 或文件年龄强拆。

锁内重读、检查实际版本，在目标同目录写独占临时文件、同步内容后原子替换，再同步父目录。支持目录 `fsync` 的文件系统同时落稳目录项；Windows 拒绝目录句柄或目录同步时，服务端明确记录降级，**只承诺进程崩溃原子性，不承诺掉电持久性**。其它同步错误返回保存失败；若错误发生在替换之后，目标可能已经更新，不能宣称回滚。同值幂等重试会补做目录同步。显式格式升级一旦进入 marker 发布阶段，失败也保留完整旧库备份，避免把已升级库的唯一恢复依据清掉。

首次写入中断留下的空目录、锁产物及精确保留名 `.tmp-<16 位小写十六进制>` 普通单链接文件，仍可识别为未初始化空域。GET 只返回空快照，不清理或创建文件。后续写入取得 OS 锁后才清理这类孤儿临时文件并初始化；任意同前缀名字、目录、链接或其它陌生内容不因此被认领或删除。已有合法库也仅在写锁内清理同一类孤儿文件，不按文件年龄强拆活锁。

**不承诺资源与布局的多文件全库事务**。客户端逐项保存，仍有未提交目标时不得显示全部已保存。网络回包丢失不等于写入未发生，同值幂等用于处理这一不确定性。坏 JSON、非法 UTF-8、无效 Markdown 头或物理类型不符返回 `file-shape-unknown`，不伪装成暂时网络故障。原始 IO 错误只留在服务端诊断，HTTP 回包不包含本机路径。

### 5. 模式由原生适配层显式选择

原生 `NativeMainPanel` 向共享 App 传持久化适配器；独立网页不传，也不用 localStorage、IndexedDB 或 Host API，继续刷新重置。

原生需要加载门禁、保存状态、失败草稿和冲突处理。成功载入基线前不能编辑；保存中的新输入不得被旧回包覆盖；冲突不能偷偷换版本重试。用户可明确重试、导出草稿，或确认放弃本地修改后重新载入。恢复已有相机后，不以初始适应画布覆盖它。

重载媒体再走同一静态安全入口；SVG 按 SVG 预算清理，不降成 HTML 预算。重复的内页品牌块删除，工具栏与外层学习品牌切换保留。安全与呈现规则仍由[无界笔记设计](../设计/无界笔记.md)和[阅读端呈现](../规范/阅读端呈现.md)定义。

### 6. 独立路由，不新增 agent 写入面

`/api/studymate/notes` 继承宿主 API 的 Host/Origin/会话认证；注册与错误信封遵循[工程约束](../规范/工程约束.md)。GET 读取独立域，POST 分别提交资源或布局及预期版本。

DTO 与上限的代码判据是 [`contracts.ts`](../../lib/notes/contracts.ts)，存储与路由分别是 [`store.ts`](../../lib/notes/store.ts)、[`route.ts`](../../lib/notes/route.ts)。本文不抄第二份字段 schema。本轮不注册 agent 自动读写笔记工具，不扫描学习工作区或外部目录，不自动选择/创建/发送真实会话，也不扩大 ADR-0010 的学习资料写入范围。

## 不选的方案

- **全量大快照**：布局会携旧正文写回，扩大跨窗口冲突范围。
- **按正文去重的不可变 blob 作权威文件**：相同正文的独立笔记会共享实体，外部编辑与副本独立需要额外间接层。
- **自造 PID/时间租约锁**：崩溃残留、PID 复用与误拆活锁需要另一套恢复协议；内置数据库的 OS 锁更小且可验证。
- **浏览器存储作原生回退**：API 失败时产生错误保存承诺，也无法满足跨项目/profile 的独立域。

## 验收与后续

默认 Node 回归验证文件往返、外部编辑冲突、布局不改正文、真实两进程互斥与崩溃放锁、非法格式/越界拒绝，以及保存中新输入和失败草稿。真浏览器验证重新载入、媒体再清理、引用重新授权和网页仍刷新重置。

归属交接、回收站、全部多笔记本、批量迁移与真实消息发送仍需独立议题。单文件原子性不是硬件故障或任意外部程序恶意竞写下的备份保证，仍应备份独立数据目录。完成前不宣称持久化已验收。
