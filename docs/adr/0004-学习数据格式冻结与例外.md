# 学习数据格式冻结与例外

重构可以推倒内部实现，但**学习工作区的布局、文件名与目录结构不动**，旧工作区直接能开。唯一的例外是进度状态词表：六档精简为三档（未开始 / 学习中 / 已学完），掌握度字段移除；读取旧文件时自动映射，写回时用新词表。

## Considered Options

- **连工作区格式一起改**：允许重划目录与 schema，配一次性迁移脚本。自由度大，但要长期维护两代知识，而动的是用户真实积累的学习档案。
- **完全不改词表，只在界面上合并展示**：零迁移，但数据里会永远残留两个没人用的档位——"需要复习"对应一个已经不存在的复习队列。

## Consequences

- 用户的学习档案零丢失，旧工作区不需要任何迁移步骤即可打开。
- 词表变更要写映射与测试；schema 更新后，旧文件在被写回前一直处于旧词表状态，读取路径必须容错。
- 路线图的状态着色从六种收敛为三种，阅读端据此简化。
