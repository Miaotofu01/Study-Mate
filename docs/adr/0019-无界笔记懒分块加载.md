# 无界笔记：懒分块加载（单一客户端入口不变）

- 状态：已实施，通过懒分块浏览器网络断言与默认门禁；状态细节以[无界笔记设计 §0](../设计/无界笔记.md#0-状态分层)为准。
- 范围：[issue #302](https://github.com/Miaotofu01/Study-Mate/issues/302)。
- 前置：[ADR-0015](0015-无界笔记模块与独立数据域.md)。单客户端入口、单 `./client` export、宿主只登记一个学习面板**均不变**；本决定只拆「首屏要不要把整个笔记子模块下载完」。
- 接续：[ADR-0016](0016-无界笔记持久化与单文件版本栅栏.md)、[ADR-0017](0017-学习节点笔记与共享即时编辑.md) 的数据与接线决定不受影响。

## 背景

正式包把阅读端与整个笔记子模块（ReactFlow 画布、CodeMirror 编辑器、KaTeX 排版与私有字体）打进同一个 `dist/client.js`，学习侧首屏为从未打开的笔记付全量下载。宿主客户端模块系统本身支持包内相对分块：`require.async('./client.<名称>.js')` 会按当前 revision 从入口同目录按需取文件、缓存成功结果、失败不缓存可重试。缺口不在宿主，而在我们的产物与登记方式从未用过它。

## 决定

### 1. 产物形态：一个入口，一个分块，仍然只有一条 export

`dist/client.js` 继续是唯一客户端入口（阅读端 + 轻量懒控制器），新增 `dist/client.notes.js` 承载笔记子模块与限域样式。分块**不是第二条客户端子路径**：`exports` 仍只有 `./client`，pack 白名单只精确新增这一个文件名，第三方 notices 覆盖入口与分块两份构建输入。

### 2. 懒控制器：加载只由用户动作触发

入口侧控制器（`client/notes/host/lazy-bridge.jsx`）交给阅读端的 `notes` 选项里，`NativeMainPanel`/`LearningNotesTree`/`LearningNotesPanel` 是**门面（gate）组件**：挂载即触发 `require.async` 加载，`createNotesWorkspace`、`PanelIcon`、`CHAT_SLOT` 仍是入口侧真实现。控制器的 `attach` 只登记上下文，绝不触发加载——学习首屏（主页、课件页、品牌切换）零分块请求。笔记的入口判据（笔记 tab、左栏切换、笔记面板、笔记面）不变，都已经是用户点击后才挂载的位置。

### 3. 状态机：明确等待、明确失败、真实重试

加载中在笔记面板原位渲染 `role="status"` 局部状态；失败渲染 `role="alert"` 与重试按钮，重试真实重发请求（失败不缓存，与宿主 `importChunk` 的 pending 语义一致）；宿主没有 `require.async`（旧宿主）时是同一个失败态，有明确文案，**不静默回退、不挂无边界 Suspense、学习面完全不受影响**。分块物化后先校验组件齐全与 `CHAT_SLOT` 恒等，再在宿主上下文上执行 `notes.apply`（注入限域样式并挂清理链），之后才进入就绪态渲染真组件；任何漂移按失败处理，不渲染半初始化的笔记。

### 4. 样式随分块走

限域 CSS 与私有字体只进分块产物；入口产物零样式。`apply` 期注入 `<style data-plugin 外、dataset.studymate-notes>` 并随宿主上下文清理，沿用 [ADR-0015](0015-无界笔记模块与独立数据域.md) 的限域规则（`.studymate-notes` 前缀、私有关键帧与字体族名）。KaTeX 版本与私有字体族第一步不动：笔记侧 0.19.1 不指向阅读端 0.18.7 的资源，统一版本留给后续决定。

### 5. 验收判据

`scripts/tests/browser/notes_lazy_chunk_test.mjs` 四场景：①学习首屏零分块请求且课件页照常；②首次打开笔记恰一次请求、学习/笔记往返保活不重拉不重挂；③注入 503 → 明确错误态 → 重试成功恰两次请求；④旧宿主无 `require.async` → 学习照常、笔记明确失败、零请求。构建报告分别记录入口与分块的 raw/gzip 字节与合计；数字以构建报告为准，不在文档里冻结。
