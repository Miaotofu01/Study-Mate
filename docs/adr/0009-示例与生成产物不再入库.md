# 示例与生成产物不再入库

删除 `examples/`。门禁改用**测试时现造的临时科目**；仓库里不再提交任何生成产物。

`examples/` 今天是"生成后入库"的示例工作区（2 门科目、各 3 课、18 个 HTML、1.8MB），与模板资源逐字节比对——它同时扮演三个角色：README 的演示入口、端到端验证的载体、模板资源一致性的基准。

## Considered Options

- **保留一份极小的 fixture 给门禁用**：简单，但它会随格式演进而腐坏——正是今天 `examples/` 的处境。
- **保留导出的 HTML 作视觉基线**：能防样式回归，但每改一次样式都要重建基线，成本随界面演进放大。

## Consequences

- 测试在临时目录现造一份最小科目（两三个节点、一课、几道题），跑完即弃。
- README 失去"clone 下来就能点开"的演示入口，改为截图或导出的示例页面。
- "逐字节比对"这类检查随之删除；门禁改为三层——数据、内容、渲染冒烟。
