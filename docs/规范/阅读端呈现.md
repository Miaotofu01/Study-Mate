## 一、课件页 · 正文（中栏）

判据是「一屏能读下去」，不是「填满窗口」：

- **正文列在面板里占得住宽度**：两条栏收起时，正文是这一页的主体，不是中间一条窄缝。
- **测宽服务于可读行宽**：画布宽了，正文列不跟着无限变宽——两侧留白明显；画布窄了，它铺满中栏。
  这条与「填满窗口」是两件事，别拿「窗口有多宽」当判据。
- **右栏并排打开时正文仍读得下去**：右栏有自己的下限，不会把正文挤成不可读。
- **窗口变窄，正文不被压成一条**：任何画布宽度下都保底一段可读的正文列。
- **配图两条路**：矢量图**随列宽流动**；位图**受列宽约束**——大图缩到列宽（既不横向溢出，也不裁掉），
  本身就小的图保持自己的比例。
- **暗色主题下配图不刺眼**：位图与矢量图在暗色里都被压暗一档；亮色下不给图加任何滤镜。
- **代码块带语言标签**；超长行在块内横向滚动，块本身不超正文列宽。
- **代码块的解释在框内、贴着它解释的那一块**：`::: code` 的 `caption:` 渲染在代码块的框里、代码下方
  （与顶栏同一层底色的那一条），一眼看得出属于哪块；按正文那一档字号，亮暗两套下都达 AA。
  `alt:` 是这一块的无障碍名字（`role="group"` + `aria-label`，不冒充 `role="img"`）。
- **行号槽按这一块最长行号的位数撑开**：两位数、三位数（10、11、…、120）也各占一行、都留在槽里，不折成两行；
  一位数的块就按一位数宽，不留空列（槽宽写死成定宽时，多位数会一个字一行地折下去，整列高度翻几倍、与代码行错开）。
- **长标识符、长 URL、宽表格不撑破版面**：段落里的长 token 断行，宽表格在自己那一层里横滚，
  页面级不出现横向滚动条。
- **课件页顶部那一条只放真正有用的入口**：课件标题、小节跳转与进度在**同一条**里（原来是分开的两条，
  各占左边一小截），且这一条不空着大半条——内容从左边距铺到右边距。
- **长标题在面包屑里省略得有分寸**：上限按**全角字**（em）算，不按 `ch`——中文下按 `ch` 算会把字砍秃。
- **字号与行高成套**：同一屏里成句的文字只有一种字号，行高跟着字号走，不出现两种正文大小并存。
- **成段的正文首行空两格、右边缘齐平**：一段的第一行比其余行缩进两个字，读者靠这两格认「新的一段
  从这里开始」；行尾两端对齐，一屏的字读下来是一条直线。缩进按**字符**算（`em`），不按像素——
  顶栏的字号四档换过之后仍然是「空两格」。**框内的段落不缩进**：列表项、提示卡、练习块、图题、
  本节目标、课头的元信息行、代码块框内的解释槽与标注弹层里的段落，各自已有边距或边框，再叠两格
  就成了三级缩进，层级反而看不出来。
- **二、三层列表靠缩进表示从属，不靠手写空格**：从属关系由 `- ` / `  - ` / `    - ` 的嵌套表达
  （每层 2 格，与 [课件内容格式](课件内容格式.md) 的 `list-indent` 判据同一个数），由解析器建成
  `item.children`、再交给 CSS 缩进；正文里手写全角空格凑缩进不算从属关系。
- **正文里的题目标记一眼看得出它属于哪一组**：标记上写着「练习」+ 组号 + 该组锚点原文 + 题数，
  组号与右栏那一组的编号对得上（点得进去，见 §二）。

## 二、课件页 · 右栏（题目 / 问答）与三栏让位

右栏是「做题与提问的那一栏」，默认收起（形状见 [目标态规格](../设计/目标态规格.md) §4.1）：

- **题型徽标是贴字的标签**：它跟着自己那行字走，不是被弹性行拉高的一根竖条。
- **展开后的参考内容按题型给字段**：`预测验证` 给 `预测` + `比对`，`交付物` 给 `交付物` + `证据`，
  `开放题` 给 `answer` + `criteria`；判分要点（`criteria`）是**共享字段**——另两种题型写了就一并
  显示，没写就不占一块只有标题的空档（条目由 [课件内容格式](课件内容格式.md) 与代码的词表定）。
- **「当前」组看得见**：点正文里的题目标记之后，右栏**恰好那一组**带「当前」标记（边与组号圈换成品牌色），
  且落在右栏的可见范围里；换一节课，标记不跟过去。
- **tab 的选中态与设计一致**：两个 tab 恰好选中一个，选中态是**下划线**（不是左栏那套胶囊），
  且 tab 条与内容同宽同起边。
- **「问答」tab 里嵌的是宿主自己的会话正文**：面板不再有自己的输入框与「问一句」——多轮、
  流式、滚动、草稿、Enter 发送、Shift+Enter 换行全归宿主那条会话；从侧边栏点开同一条会话，
  看到的是同一套界面与同一段对话。顶部两个入口：「新对话」（另起一段）与「上一段会话」
  （只列答疑会话，最近的在前面）。**刷新页面回到最近那段**（会话落在磁盘上）。
  没有可用模型时如实说明、不假装会答；无头宿主（没有阅读端）那条路照旧（`local-qa` 就地答）。
- **上一次作答的结果看得见**（这能力早就有，别丢）：来自 `attempts/` 的那一句在右栏里；就地作答之后，
  它换成刚落下的这一次。
- **右栏只出现纵向滚动条**：长题干与长选项在卡片里断行、不被裁掉，右栏自己不顶出横向滚动条。
- **并排装不下时给解释与出路**：画布窄到并排放不下右栏时，点「题目」得到的是**盖在正文上的抽屉**
  ——顶上写着为什么（窗口太窄、拉宽就并排）加一条「收起」，题目本身照样做得成；**静默失败不算实现**。
  抽屉一次只给最近点的那一栏（开一栏不顺手把早先要过的另一栏盖上来）。
- **让步不写回记忆值**，画布变宽自动回到并排。
- **不出现「两栏都打不开」的画布宽度区间**：任何宽度下，最近点的那一栏要么并排、要么以抽屉出现；
  并排的两条栏加起来也永远不挤破中栏的保底。

**让位顺序与阈值（右栏先拿、左栏先让、中栏保底；并排的极限在哪）的唯一出处是
[ADR-0011](../adr/0011-阅读端三栏让位顺序.md)**，本文不复述那些数字。

## 三、主页 / 科目主页 / 搜索

- **主页（工作台）第一屏就告诉去哪继续**：「接着上次」那张卡点得进去，落到的就是它说的那个节点；
  一次都没开始时卡上改说「从这里开始」。**这张卡取哪一门、放哪一格归
  [目标态规格](../设计/目标态规格.md) §4.1**（spec 里这页叫「今天学什么」，那是早先的措辞，已作废），
  本文只管「第一屏就得指得出路，且指的地方真去得了」。
- **空目录与半份数据给得出「没有」**，不是一片空白、也不是错误卡：空工作区说「还没有科目」
  并说清读的是哪个工作区；零节点的科目在卡上写明「还没有节点」；没有课件的节点在路线图卡上写明「无课件」；
  参考资料那一块给「还没有」。
- **一门科目的文件读不了，只坏那一门**（#222）：`curriculum.yaml` / `subject.yaml` 解析失败或形状
  不对时，其余科目照常打开，主页上点名**哪门科目**、**哪份文件第几行**、原文是什么，学生改完点重试。
  整页「读不到学习工作区」只留给真正读不到工作区的情形（`.learning/subjects/` 不在、`workspace` 没配）。
  数据层为此有一个显式开关（`readLibrary({ isolateBrokenSubjects: true })`）：导出与原生工具要完整
  快照，仍走「坏数据当场抛错」的默认。
- **路线图里不出现连线或箭头**，前置关系写在卡片脚印里（「前置：变量」/「无前置」）——这是决定，
  不是漏画（取舍见 #152）；读屏用户照旧拿得到那张视觉隐藏的表。
- **搜索结果每一条都看得出它属于哪门科目、哪个节点**；无断点的长 URL 撑不破结果行，
  覆盖层不撑出视口。

## 四、四个面共同的

- **每一处文字在亮暗两套主题下都过得去对比度**：WCAG AA（4.5:1——这是标准给的比值，不是我们定的取值）。
  页面侧由浏览器套件按取样点合成背景后算实测比值，四个面 × 亮暗 × 各档视口逐场跑；
  token 侧的同一条纪律（每个文本 token 压在每个表面上）见 [目标态规格](../设计/目标态规格.md) §4.2。
- **动效四档可切并跟随系统偏好**：`auto` / `full` / `reduced` / `off`；显式档位记在浏览器本地偏好里，
  系统 `prefers-reduced-motion: reduce` 只影响 `auto` 档（显式的 `full` 不受它改写）。
  档位语义与「跟宿主保持一致」的来由见 [目标态规格](../设计/目标态规格.md) §4.4。
- **字号四档可切，默认档不变**：`standard`（默认）/ `medium` / `large` / `xlarge`，记在浏览器本地偏好里，与栏宽、动效档同级。
  换档换的是**整条字号阶梯**（六个字号一起放大），行高比四档一致——所以「同一屏里成句的文字只有一种字号」
  在每一档里都成立；只放大正文会让块标题反被正文顶上去，那正是要避免的两种正文大小并存。
  元信息档（角标、chip、控件文字）不跟着放大：它们不成句，尺寸跟着控件走。
  档位与 token 的对应关系见 [目标态规格](../设计/目标态规格.md) §4.4。

## 六、问答面板 · 引用的保持行为

引用（选中正文的那一段）在**捕获那一下冻成一条数据**：`{ 文本, 来源锚点 }`（锚点=哪一课、哪一小节）。
面板只渲染这条数据、只把它随问题一起送出去，**自己不去读实时选区**——面板一打开就会聚焦输入框，
那会儿实时选区已经没了。据此：

- **选中正文 → 面板的输入框上方出现一颗看得见的引用 chip**：一行写着原文与它的来源小节，点得开看完整原文，
  右边一颗「删掉」；从正文发问时右栏的「问答」tab 自己滑出（附带一条浮动胶囊「就这段问一句」是入口，不是引用本身）。
- **那颗 chip 是承重件，不是装饰**：学生在正文里划中的那段，同时被放进**那条会话的草稿**（走会话的输入门面）。
  宿主没有提交钩子——草稿里没有它，消息就不会带上它。提交那一刻由我们注册的引用来源的 codec 决定进消息的
  那段文字（**原文 + 来源锚点**），所以那个来源在插件激活时注册、随插件卸载注销；它不在册时发送会被拦下、
  草稿还给学生。
- **只在选区确实落在正文里、且长度达标时才更新引用。** 太短的选区不算数——**当前取值**是不足四个字
  （按码位数），写在 [`lib/client.js`](../../lib/client.js) 捕获那一处；规范要的是「双击单词、误触这类
  噪音不该变成一条引用」，不是那个数字本身。
- **只跟下一条消息走**：同一段会话里只挂一条引用，**再选一段就把旧的换掉**，学生不用先删。
- **读到空选区不得清空已存在的引用**：在输入框里打字、点面板里别的地方、切到「题目」tab 再切回来，
  引用都还在。**病根就是这条**：文档级 `mouseup` 每次点击都会冒上来，而点输入框会让浏览器把选区折叠成空
  ——「这一次没划中」不等于「学生不要这段引用了」。
- **清除只有两处**：学生点引用上的「删掉」，或**这条消息真的提交出去**——提交那一刻引用已随消息进了会话，
  再留着只会让下一问带上上一问的。**不必等答成才清**：流式回答还没写完、甚至这条链路上没有可用模型，
  只要消息送出去了，这一颗就该让位给下一段。提交没成功（例如宿主把发送拦下、草稿被还原）时引用留着——
  那一次什么都没送出去。
- **提交时引用随这条消息一起进会话**（文本 + 来源锚点），**不写进学习工作区**，也不落进任何学习内容文件
  ——面板不再写误解记录（口径归 [目标态规格](../设计/目标态规格.md) §7.4）。
- **一次只引一段，不要求多段**；**没有引用时面板照样能用**（提问不带那一段，不写空壳锚点）。
- **没有可用模型时如实说明**：不假装会答、不编内容。
- 面板的上下文边界（课件用只读工具按需取 + 选中的这段随引用 chip 进消息 + 开张时注入的共享记忆）归
  [目标态规格](../设计/目标态规格.md) §7.4，本文不重复。

## 七、技能与工具的可见边界（指向工程约束）

**唯一出处是 [工程约束](工程约束.md) §二「技能与工具的可见边界」**，本文不复述。从本 spec 过来的人
只需要知道两件事：

- **技能可见范围由预设自己声明**（技能源住在包内的 `preset/skills/`：学习预设声明整棵，答疑预设只
  声明它那一个 `local-qa` 子目录），**不依赖「会话恰好不在这个仓库里」**——这一条已达成。
- **工具、面板与 slot 不守同一条边界**：前提（宿主提供「按预设注册工具/面板」的接口）不成立，
  属**宿主侧缺口**，不改实现，改为把现状钉住。所以这一轮有两条**没整条达成**：用户故事 36
  （工具/面板/slot 守同一条边界）**未达成**；用户故事 37（一条自动化检查证明「别的预设里看不到
  StudyMate 的**技能与工具**」）**部分达成**——技能那一半由那条检查证明，工具/面板那一半它断的
  是反面（那条断言钉的是现状：标准预设的会话里也看得见）。
  为什么、现在是什么样、去向在哪，都在工程约束 §二那一节里；钉住它的是
  `scripts/tests/test_skill_visibility.mjs` 的最后一条断言（哪天有人收紧注册面，它会红）。

## 九、无界笔记（呈现判据）

无界笔记与上面六个面**不是同一类东西**：它是独立的内容工作空间，不是课件右栏里的附件。它与学习页面在同一个
「学习」宿主面板内切换，不另设宿主侧栏入口（注册边界归 [工程约束](工程约束.md) §二「客户端单入口与无界笔记的构建」；
产品语义归 [无界笔记设计](../设计/无界笔记.md) §6.2）。这一节只判「看起来对不对」。

**持久化状态不在本节复述**：正式 DSH 入口的持久化、独立网页的内存刷新重置与验收状态，以[无界笔记设计](../设计/无界笔记.md) §0「状态分层」为唯一出处。下面每条都是当前实现的呈现样子，
不是「已完成的笔记功能」的证据。

判据（照 §4 同一口径：意图级、不带数字阈值，取值落在 [`client/notes/`](../../client/notes/) 那一处）：

- **品牌承担两面切换，不再承担回主页**：学习时顶栏为「StudyMate ⇄ 无界笔记」，笔记时为「无界笔记 ⇄ StudyMate」；当前名称在前、目标名称在后，中间是小型互指图标。品牌字号比普通操作文字更突出。点击或键盘激活整颗品牌按钮进入目标面，笔记状态的左侧品牌标记使用模块自有的无界符号，不用学习的「学」字冒充。内页不再重复出现品牌块；内页工具栏与状态条保留。
- **学习内部导航仍可用，共享偏好两面通用**：学习模式保留「学习工作台」面包屑和搜索；无界模式顶栏不显示搜索和学习面包屑（也不可聚焦），回学习使用品牌切换。字号与动效选择在学习与无界笔记两面共享并保持生效，同一宽度与字号下两面外层顶栏高度保持一致。切到笔记不丢学习位置，切回学习不丢笔记场景、布局或正文。隐藏的面不能接收焦点与快捷键；刷新重置与两面切换保留是两种不同操作。
- **学习侧栏只编辑原笔记**：左栏「课程／笔记」切换与右栏「笔记」tab 保留原三栏让位；右栏不是整套无界画布。左栏只列「节点 → Markdown」，所有当前课程节点保留，包括空节点；首次新建先显式定默认本。
- **两面是同一份 Markdown**：无界节点视图与学习树复用课程关联。拖笔记换节点只改关联，不搬原件、不改正文或画布；换默认本只影响未来新建。打开、移动光标、选区和显隐标记不自行保存，未支持语法保留原文，不经全篇规范化改写。
- **局部语法可直接修改**：光标或选区触及的格式片段露出真实、可编辑的灰色 Markdown 字符，文字仍保留粗体、斜体等排版；其它片段继续渲染，不将整段切为源码。渲染编辑只有一条格式栏，不套卡片，无重复正文标题和常驻说明；列表的非活动项用各自标记和缩进区分。独立文档页顶部出现四种模式；两个狭窄的快速编辑侧栏没有模式切换。完整视图行为见[无界笔记设计 §7](../设计/无界笔记.md#7-markdown-编辑与外部来源)。
- **资源操作贴合对象**：资源树行的更多菜单在触发键旁，边界不够时向上展开，触发键滚出可见区即关闭。无界资源详情的 Markdown 编辑面从标题与必要信息下方铺满右栏，保留文字内边距，长文只滚正文。
- **归属可见，关系就近管理**：无界本名旁显示绑定摘要，绑定从本行菜单管理；无界快速编辑右栏在文件名旁用同一个按钮显示关联科目（无关联显示「未关联」）并打开管理。资源树不加未知类型标签，打开不支持的笔记只显示「不支持的文件类型」。学习左栏「笔记」顶部显示默认本及「课程笔记本」入口，笔记行可辨所属本；右栏只选或新建当前节点的笔记，标题下显示原件目录。无界新建操作集中在左栏顶部一个菜单。
- **笔记正文用中性色面**：亮暗正文均与宿主背景区分，暗色用中性深灰，不带绿底；不改宿主背景。引用在编辑和预览时均用可辨认的左边线和缩进区别于普通段落。有语言的代码块在代码上方右侧显示无胶囊边框的语言标签，不遮挡代码。三处笔记的 Markdown 导出均用标题行的小图标，不另占一行；导出仍读取当前原稿。
- **课程卡只有标题与跳转**：不带摘要或正文预览；选中后右栏只读显示实际课件，按完整来源精确跳回课程并保留画布。失效链接保留原名称，不能按同名猜测。
- **画布里的卡片一眼分得清是什么**：笔记卡、课程卡、网页/外部资源、静态媒体卡、纯文本节点各有可辨认的形态，
  不靠读标题猜。纯文本节点**没有页头**，整块可拖；带页头的卡片才有折叠箭头。
- **关系说明为空时不占位**：只剩线本身，画布上不出现空标签卡片；补写之后标签回到线中间、属于那条线。
- **折叠只说三件事**：压成一行、恢复回折叠前的高度、折叠期间**旧正文位置不再留可命中的透明块**
  （笔记与媒体卡成立；课程引用卡仅保留标题和跳转，无页头的纯文本节点不提供折叠）。折叠是呈现，不改变内容身份，也不进正文编辑器的撤销栈。
- **静态媒体只做静态呈现**：图片或 HTML/SVG 页在卡片里可读、可滚动，**没有脚本在跑、没有外网请求**；
  沙箱与「不执行 JS、不加载外网」的边界归 [无界笔记设计](../设计/无界笔记.md) §10.3，本文不复述。
- **右侧会话面板在正式入口里就是宿主那条会话**：与阅读端其他地方同一套原生会话、显式选现有会话、
  引用只进草稿——笔记不是把会话能力退回占位的理由。**占位只出现在网页验收入口**：那页没有宿主，
  面板明说没连会话、发送不可用，不假装有模型。两处都不出现「看起来能发、点了没反应」的按钮。
- **左侧资源树与右侧面板收起后还回得来**：留一条窄轨或顶栏开关，状态不丢、宽度不跳。
- **亮暗与对比度照 §四**：无界工作空间与学习侧栏笔记**默认跟宿主主题**；顶栏提供显式明暗切换，覆盖只作用于笔记模块自身（宿主其余界面不动），本页会话内保持，刷新回到跟随宿主。左树、标题和表单、状态提示、格式栏、灰色语法字符、正文与代码在亮暗两套下同样达 WCAG AA，覆盖态下的呈现也一样。不能只给画布适配暗色。
- **刷新之后独立网页如实回到初始状态**：独立网页无持久化适配，刷新重置**就是当前正确行为**，不是缺陷——
  界面上不得出现「已保存」之类的暗示。

无界笔记的浏览器与纯函数套件、前置和覆盖范围见[测试说明](../../scripts/tests/README.md#浏览器套件与手动工具)。
**验收状态**：独立网页入口的自动化套件只覆盖内存态交互；正式 DSH 入口的持久化走向与验收状态以[无界笔记设计](../设计/无界笔记.md) §0 为唯一出处。
