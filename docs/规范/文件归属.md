# 文件归属（代称 ↔ 路径 ↔ 维护者）

**这份表是文件「代称、功能、路径、维护者」的唯一出处。** 角色规格（`preset/skills/*/SKILL.md`）在正文里用「代称」指代文件，不再反复写全路径；要判断自己有没有权改某份文件，查这张表的「维护者」一列。

## 怎么用

- 代称在 SKILL 正文里写作「共享记忆」这样用「」框住；本表第一列写裸名
- **角色也有代称**（见下节）：正文里可以直接用「总控」「讲解」这类叫法；**「维护者」一列写技能名**（按角色代称表对应），或者写 **`所有角色（直写）`**——后者表示这份文件不收在某个角色手里，谁在干活谁收尾时自己往里写，不经总控转交。今天只有两份记忆是 `所有角色（直写）`：往「积累」追加一行，判据与写法见 `record-keeping` 的「共享记忆」节
- **路径前缀**：`<root>` = 引擎仓库根；`<LEARN_WORKSPACE>` = 学习工作区；`<subject_path>` = `<LEARN_WORKSPACE>/.learning/subjects/<slug>`；`<DSH_HOME>` = 宿主 `profileContext.home` 给出的 DSH 数据根
- 本表**不重复**各角色的边界正文：边界仍写在各自规格里，只是可以改用代称
- **收录范围**：① 角色与协议规格正文里会提到的文件；② 学生或维护者要用的仓库入口（安装说明、工程约束、本表）。**不收纯开发工具**（发布、打包、预览脚本一类）

## 角色代称

角色（谁在干活）也有代称，正文里可以直接用。**派工给什么值由各角色规格的「输入」节定义**——值归消费者，它最清楚自己需要什么；本表只回答「谁维护哪份文件」，不再复述派工值。本表其余各节的「维护者」写的是技能名；**唯独两份记忆（共享记忆、科目记忆）写 `所有角色（直写）`**——它们是全角色收尾时直接追加的，没有单一维护者。

| 代称 | 技能名 | 一句话职责 |
| ---- | ------ | ---------- |
| 总控 | `learning-system` | 开场、盘问、调度、档案；唯一有用户通道的角色（学生只跟你说话） |
| 资料收集 | `resource-scout` | 收集权威教材与官方核对来源，产「资源清单」；把本地教材与可取到正文的来源转成 Markdown 入库 |
| 采图 | `image-scout` | 抓网页现成的位图，落「图片库」与「图片库索引」 |
| 课设 | `curriculum-designer` | 产「课程大纲」与实验课节点 |
| 讲解 | `learning-coach` | 写「课件内容文件」与「速查页」；配图规范的 owner |
| 出题评估 | `practice-evaluator` | 题目唯一 owner：出题、判分、**实验课验收**（结论写进「学习记录」；不写「评估记录」；阶段评估已删） |

## 四、仓库侧 · 无界笔记

无界笔记的数据不在工作区表里：它有自己的数据域，不属于 `<LEARN_WORKSPACE>` 或插件安装产物。
首轮路径与格式由 [ADR-0016](../adr/0016-无界笔记持久化与单文件版本栅栏.md) 登记；当前实现与验收状态见 [无界笔记设计 §0](../设计/无界笔记.md)。

| 代称 | 路径 | 功能 | 维护者 |
| ---- | ---- | ---- | ------ |
| 无界笔记共享源码 | `client/notes/` | 画布、资源树、编辑器、媒体渲染等组件的唯一源码；由 `build:client` 打进正式包的 `dist/client.js` 与其唯一分块 `dist/client.notes.js` | 仓库维护者 |
| 笔记宿主适配 | `client/notes/host/bridge.jsx` | 把宿主能力转成组件 props 的适配层；**正式 DSH 入口复用已验证的原生会话适配**（显式选现有会话、引用只进草稿）；占位只在网页入口 | 仓库维护者 |
| 笔记网页入口 | `prototypes/unbounded-notes/`（`index.html`、`vite.config.js`；依赖共用根包） | 保留的网页开发与自动化验收入口，引用同一份共享源码 | 仓库维护者 |
| 笔记 Host 数据层 | `lib/notes/` | 独立域读写、版本栅栏与精确路由；不注册 agent 自动笔记写入工具 | 仓库维护者 |
| 独立笔记数据目录 | `<DSH_HOME>/studymate-notes/` | 用户的笔记、逻辑文件夹、各笔记本画布与课程关联元信息；不属于学习工作区或安装产物 | 无界笔记 Host 存储（用户经正式界面操作） |
| 自有笔记文件 | `<DSH_HOME>/studymate-notes/resources/r-<id>.md` | 稳定 ID 对应的单份 Markdown 正文与头部元信息 | 无界笔记 Host 存储 |
| 笔记资源元信息 | `<DSH_HOME>/studymate-notes/resources/r-<id>.json` | 非笔记资源及外部文件引用元信息；引用不持久化来源权限或正文 | 无界笔记 Host 存储 |
| 笔记画布布局 | `<DSH_HOME>/studymate-notes/layout.json` | 逻辑文件夹、按笔记本分区的卡片与关系、各本相机，不包含资源正文副本 | 无界笔记 Host 存储 |

`client/` 与 `lib/` 谁供谁用、CSS 与 React 的边界，归 [工程约束](工程约束.md) §二「客户端单入口与无界笔记的构建」；
数据域的边界归 [目标态规格](../设计/目标态规格.md) §4.3 与 §4.6。**本文只记路径与谁维护，不复述那些规则。**
