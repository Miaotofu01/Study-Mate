# 安装与更新

DSH 用 `dsh plugin` 装插件；Codex 下载 ZIP 后导入。两种宿主使用同版本的技能与 schema，学习数据都保存在独立工作区。

导出静态页面时另需一份 React（`npm i -g react react-dom`，或用 `STUDYMATE_REACT_DIR` 指过去）；只学不导出的话不用装。

## DSH

需要 **DSH 0.1.7-alpha.1 及以上**、Node.js（支持范围见 `package.json` 的 `engines`），以及 PATH 上的 `pnpm`——`dsh plugin` 就是把参数转给 pnpm。**不需要 Python**：引擎是随包发的 TypeScript 插件。

装插件（macOS、Linux、Windows 同一条；`web` 是 `dsh web` 用的档位）：

```sh
dsh plugin --profile web add @yunmiao/studymate
```

装完**重启 DSH**，新建会话时选「学习模式」，从侧边栏切到阅读端。插件第一次启动时会自己把引擎路径与两条预设（学习模式、答疑模式）配好；学习工作区默认 `~/StudyMate`，已有配置优先。

装完看不到学习模式、阅读端或工作区时，先跑 `npx -y @yunmiao/studymate@latest doctor`；它只读检查，详见[诊断说明](诊断.md)。

### 更新

```sh
dsh plugin --profile web update @yunmiao/studymate@latest
```

然后重启 DSH 并新建会话。旧版通过源码安装的用户也走这条：档位里那份插件换成新的，工作区原样沿用。

### 桌面端（DeepSeek Harness Desktop）

桌面端自带 DSH，不需要再装官方 CLI。

1. 桌面端**至少启动过一次**——它要先在 `~/.dsh/profiles/desktop/` 建出自己的档位，安装器才认得。
2. 把档位换成 `desktop`：

   ```sh
   dsh plugin --profile desktop add @yunmiao/studymate
   ```

   手边没有 `dsh` 命令时，用桌面端的插件市场按包名 `@yunmiao/studymate` 装——后台是同一件事。
3. **完全退出 DeepSeek Harness，再重新打开**（正在运行的窗口读不到刚装上的插件）。
4. 新建会话时选择「学习模式」。

### 官方 CLI（`dsh web`、`dsh tui`、`dsh headless` 等）

没有桌面端时，先安装提供 `dsh` 命令的[官方 CLI 包](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/cli/package.json)：

```sh
npm install -g @deepseek-ai/dsh@latest
dsh plugin --profile web add @yunmiao/studymate
dsh web
```

其他已创建的档位用 `--profile <名称>` 指定：

```sh
dsh plugin --profile headless add @yunmiao/studymate
```

### 低于 0.1.7-alpha.1 的 DSH：只能装引擎材料

老版本没有原生插件接口，装插件那一步走不了，只能用安装器：

```sh
npx -y @yunmiao/studymate@latest install
```

这条只把引擎材料拷到 `~/.dsh/studymate/engine/`、在档位里写一条「学习模式」声明；「答疑模式」留到装插件时才有。**阅读端、答疑面板、九个学习工具都不会出现**——它们都长在插件里。能升级 DSH 就升级。

指定学习工作区、或桌面端装在非默认目录时也走这条：

```sh
npx -y @yunmiao/studymate@latest install --workspace "D:/StudyMate-workspace"
```

指定目录只改变后续读写的位置，不会自动搬迁原有学习数据。换目录或换机器时，先复制整个学习工作区（包括隐藏的 `.learning/`），再安装并指定复制后的路径。

桌面端装在非默认目录时（Windows 默认 `%LOCALAPPDATA%\Programs\DeepSeek Harness`），用 `--dsh` 指向它自带的 dsh：

```powershell
npx -y @yunmiao/studymate@latest install --dsh "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"
```

```sh
# macOS
npx -y @yunmiao/studymate@latest install --dsh "/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"
```

不指定 `--profile` 时，安装器按下面的顺序决定装到哪个档位：

1. `--dsh` 指定的、或 PATH 里的 `dsh` 属于桌面端 → `desktop`；
2. 之前装过一次 → 沿用那次记录的档位（升级时不会因为 PATH 变化装到别处）；
3. 其余情况 → `web`。

PATH 里的 `dsh` 版本过旧（低于 0.1.5-rc.2）时会被跳过，继续找桌面端自带的那个；两个都不能用时，报错会指出找到的版本和位置。

要看住哪个档位，就显式写出来：`--profile desktop` 或 `--profile web`。

### 目录与工作区

默认学习工作区是 `~/StudyMate`，已有配置优先；装在哪个档位、工作区在哪，记在 `~/.dsh/studymate-config.yaml`（设置了 `DSH_HOME` 时用对应目录）。装了插件的档位不需要引擎副本：插件自己就是引擎，技能直接从这个包里读；老版本那条 `npx` 命令才会在 `~/.dsh/studymate/engine/` 留一份引擎材料。

## Codex / ChatGPT Work

**支持范围：只有 `v1.0.0`。** 1.1.0 起的版本不再保证在这一侧可用（[Codex 与 ChatGPT](Codex与ChatGPT.md)、[Antigravity](Antigravity.md) 同）。

1. 从 [`v1.0.0` 的 Release](https://github.com/Miaotofu01/Study-Mate/releases/tag/v1.0.0) 下载 **studymate-openai.zip**。
2. 通过 Codex 客户端提供的插件导入入口安装该 ZIP；没有导入入口时，按 [导入说明](Codex与ChatGPT.md) 使用插件创建器。
3. 新建任务，选择 StudyMate 的 `learning-system` 技能，并说明学习目标和工作区路径。

换机器或重装时用上面同一个 ZIP；保留原学习工作区即可继续学习。

ChatGPT Work 的使用条件、工作区说明与导出见 [Codex 与 ChatGPT](Codex与ChatGPT.md)。
