## 1. 目标与核心原则

无界笔记是用户拥有的知识组织工具：用 Markdown 记录思考，用无限画布组织笔记、课程节点和外部资源之间的关系，不做绘图白板。

核心原则：

1. **原文唯一**：同一篇笔记只有一份正文；资源树引用和画布卡片不复制正文。
2. **归属唯一、可以交接**：一份内容只有一个原件归属位置，但能在多个位置被引用。跨笔记本拖动原件可以交接归属。
3. **内容身份与位置分离**：笔记本与笔记使用稳定 ID；改名、移动、交接归属不改变内容身份，不破坏已有引用。
4. **来源显式**：原件、引用、失效引用在界面上可以区分，不按同名内容猜测替代来源。
5. **用户控制内容**：首版不让 agent 自动读取、修改笔记或重排画布。
6. **保存不等于覆盖**：自动保存需要版本冲突保护，失败或冲突不能静默丢弃未保存内容。

## 2. 入口与界面

### 2.1 入口

- 在「学习」界面顶栏通过品牌切换进入无界笔记；左侧全宽入口与 DSH Web 右栏入口都打开同一个阅读端，不另设笔记标签。品牌文案、图标与状态保持判据见 [阅读端呈现](../规范/阅读端呈现.md) §九。
- 绑定科目的主页提供相关笔记本快捷入口。
- 完整笔记本工作空间不塞进课件右栏；无限画布仍通过品牌切换进入。
- 学习左栏增加「课程／笔记」切换，右栏增加「笔记」tab，只编辑一篇原 Markdown，不复制正文，也不放入整套画布工具。
- 保留现有三栏让位与窄栏入口；无界工作空间内部的左侧资源树、右侧笔记展开区仍不占用宿主整块侧边栏。

### 2.2 工作空间

- **左侧**：文件夹式资源树，统一管理笔记本、文件夹、Markdown 笔记与资源引用。
- **画布区**：打开笔记本默认进入其专属无限画布。
- **侧边笔记区**：点击笔记卡片可以展开完整笔记；原件可以编辑，引用先预览并提供「打开原件编辑」。
- 画布卡片展示渲染后的正文片段；原文更新后，各处预览跟随更新。
- 同一个 DSH 浏览器标签退出「学习」后重进，恢复学习／笔记面、画布或文档位置，以及各篇笔记独立的文档模式。界面状态仅限本标签、本工作区，不写入笔记数据域；不承诺整页刷新、关标签、跨项目或跨设备恢复。

本阶段只确定界面职责，不冻结组件库、尺寸、图标、动效或具体布局实现。

## 3. 资源树与科目绑定

### 3.1 层级示意

以下名称均为概念示例，不是仓库路径或最终磁盘布局。

```text
资源库
├─ 公共资料/
│  ├─ 阅读方法〔原件〕
│  └─ 某个网页〔外部引用〕
└─ 数学/
   ├─ 线性代数〔笔记本，可绑定科目〕
   │  ├─ 无界画布〔固定、唯一〕
   │  ├─ 概念/
   │  │  └─ 向量空间〔原件〕
   │  └─ 阅读方法〔引用〕
   └─ 复习整理〔笔记本，可不绑定科目〕
      ├─ 无界画布〔固定、唯一〕
      └─ 向量空间〔引用〕
```

### 3.2 层级规则

- 资料库根与公共区域可创建普通文件夹和 Markdown 笔记。层级设计允许公共文件夹容纳笔记本，但**当前新建入口只在资料库根创建笔记本**，具体见 §6.2。
- 笔记本内可以创建普通文件夹和 Markdown 笔记，不能再嵌套创建笔记本。
- 一篇笔记的原件可以归属于公共资源区，也可以归属于某一本笔记本。
- 文件夹内可以放入原件或引用；不因放入引用就取得目标正文的归属。

### 3.3 科目绑定

- 一本笔记本可以不绑定科目，也可以绑定多个科目；一个科目可以在多本中有笔记，不强制一科目一本。
- 每科目首次新建笔记时，显式选择或创建默认笔记本；后续新建进入该本并关联当前节点。更换默认本只影响未来新笔记，不搬动已有原件。
- 学习目录只展示「节点 → Markdown 笔记」，无自定义分类文件夹。无界保留资源视图，并增加「笔记本 → 节点 → Markdown 笔记」节点视图。两处使用同一套课程关联，不各存一棵树；学习按科目聚合，无界按原件所属笔记本聚合。
- 节点间拖动只替换当前科目的关联，不改原件父目录、正文、内容 ID 或画布。所有当前可解析课程节点都保留，包括没有笔记、没有课件的节点。
- 选择默认本同时建立科目绑定；一个科目至多有一个默认本。解除本级绑定不改变单篇关联；若该本仍是默认本，须先改选或清除默认本，清除后下次新建再选择。绑定不自动给本内笔记关联节点。
- 单篇关联以工作区、科目和节点确定；同篇在同科目至多关联一个节点。首次关联直接保存，同科目从一个节点换到另一个节点必须确认，管理入口与节点拖放遵守同一规则；其他科目关联与原件不变。
- 学习右栏只跟随当前节点，不沿用上一节点的编辑目标；学习左树可见整科目，点击另一节点的具体笔记先切换节点再打开原件。
- 绑定用于分类与默认上下文，不限制其他科目的课程引用；解除绑定或删除科目不连带删除笔记本。

## 4. 原件、引用与文件夹引用

### 4.1 原件与引用项

| 概念 | 含义 |
| --- | --- |
| 原件 | 由资源库或某个笔记本拥有的内容，只有一个归属位置 |
| 引用项 | 指向原件或外部目标的入口，不拥有目标正文 |
| 画布卡片 | 画布中的展示对象，引用内容身份，保存自身位置、尺寸及连接关系 |

「原件／引用」描述内容归属，不是区分文件是否位于本机。外部文件位于本机，也不因此成为笔记本拥有的正文。

### 4.2 引用项的显示与编辑

- 未设置别名时，引用项名称跟随原件标题。
- 引用项可以设置自己的显示名称和简短备注，不修改原件标题或正文。
- 设置别名后，仍能查看原件名称及归属。
- 引用项在侧边区可以预览全文，并明确显示来源；修改正文必须使用「打开原件编辑」，进入原件上下文，不在引用位置悄悄修改源内容。
- 归属交接时，各位置已有的显示名称不因原件／引用身份互换而丢失。

### 4.3 文件夹引用

- 允许引用整个文件夹；它显示源文件夹当前内容，不是创建引用时的一次性快照。
- 源目录的新增、移除或改名反映到引用位置。
- 引用位置不能修改源目录结构；需要打开源文件夹管理。
- 引用文件夹与普通文件夹需要有不同标记。
- 添加引用、移动目录或交接归属时，拒绝形成直接或间接的文件夹引用循环，并说明导致循环的关系。
- 外部修改导致已有结构出现循环时，界面显示异常入口并停止展开，不无限递归。

## 5. 拖拽与归属交接

**当前资源视图**：文件和非根普通文件夹可拖到新的父目录。跨笔记本或移入／移出公共资料先确认，直接移动、不在原位置留条目；正文、身份、已有画布引用和课程关联不变。笔记本不是拖动来源。拖到画布仍只创建引用，节点视图换节点仍只改变课程关联。

以下带原位置引用的交接是设计目标，尚未实施。它不把所有拖拽都解释成普通文件系统的剪切：

| 操作 | 结果 |
| --- | --- |
| 同一归属范围内拖动原件 | 调整原件在该范围内的位置 |
| 从公共资源区拖动原件到笔记本 | 默认建立引用，公共原件保留；不自动交接归属 |
| 跨笔记本拖动原件 | 交接归属：目标成为原件位置，原位置留下引用 |
| 拖动引用项 | 移动引用入口，不自动改变原件归属 |
| 在引用项执行「将原件归属转到此处」 | 明确确认后交接归属 |

### 5.1 交接示例

```text
交接前：
A / 概念〔原件〕
B / 概念〔引用〕

交接后：
A / 概念〔引用〕
B / 概念〔原件〕
```

- 目标没有该内容的引用时，在目标建立原件入口，原处仍留下引用。
- 目标已有同一内容的引用时，直接提升该引用，不额外生成重复条目。
- 内容 ID、正文以及其他位置的引用保持不变。
- 界面应明确区分移动入口与交接归属，不能让用户放下后才猜测结果。

### 5.2 文件夹交接

- 文件夹中的原件与子文件夹整体交接归属。
- 内部已有引用仍是引用，不把引用目标也搬过来。
- 原位置留下对该文件夹的引用。
- 操作整体成功或整体失败，不允许一部分原件归 A、一部分归 B 的中间结果。
- 笔记本专属画布不参与目录交接，笔记本嵌套限制仍然有效。

跨笔记本交接归属是首版能力；不采用早先讨论过的「跨笔记本拖动只能新建引用、不能交接归属」限制。

## 6. 笔记本专属画布

### 6.1 生命周期

- 每本笔记本创建时自动创建一张画布，在该笔记本顶层固定显示。
- 画布不能独立新建、移动到其他笔记本或单独删除。
- 允许清空画布，需要明确确认；清空不删除原笔记和外部来源。
- 画布随笔记本进入回收站或恢复。

### 6.2 卡片与连接

首版有三类卡片：

| 类型 | 行为 |
| --- | --- |
| Markdown 笔记 | 预览正文，侧边展开完整笔记，按原件／引用规则进入编辑 |
| 课程节点 | 画布只显示标题与跳转按钮；选中后侧栏只读显示实际课件，跳转精确回到来源节点 |
| 外部资源 | 显示资源信息，打开原来源 |
| 纯文本节点 | 画布上直接随手写的短文字，**不是笔记**：不占资源树位置、不参与引用与归属、不能被其他位置引用 |

- **纯文本节点与笔记的界限**（已确认）：要写一段会留下来、会被引用、会进搜索的字，就建 Markdown 笔记；
  纯文本节点只服务「在画布上临时标一句」。它与「独立便签」不是一回事（§10.2 仍然不做便签），
  区别在它没有身份、没有正文文件、不进资源树。
- **静态媒体**（已确认）：图片与 HTML/SVG 静态页可以落到画布上，作为**卡片**展示。它们只做保守的静态呈现——
  不执行 JavaScript、不加载外网资源；安全边界见 §10.3。媒体卡与笔记卡共用折叠、拖动、连线那套行为。
- **副本与引用**：从左侧资源树拖已有资源到画布只建立引用，不弹复制选择；外部文件导入或拖入画布时显式选择副本或引用。副本产生新的内容身份，与来源互不影响；引用只指向原件，按 §4.2 的规则预览与编辑。
- 「复制 Markdown」由 Markdown 行菜单显式创建同目录独立笔记和新 ID，仅复制原稿，不继承课程关联或上画布。支持可读取的外部 Markdown 引用。
- 资源树共用「新建」菜单：笔记本建在资料库下；文件夹和笔记按选中位置确定父目录（选中文件取其父目录，无选中取活动本），提交前显示目的地。
- 改名仅在扩展名变化时二次确认。变为不支持的扩展名后提示类型不支持，不提供 Markdown 编辑、预览、复制或导出；物理文件类型、正文、ID、位置、画布引用和关联不变。改回支持的 Markdown 扩展名即可恢复，不批量改写旧名称。
- 支持画布平移、缩放、卡片拖动和调整大小、连线及简短关系说明。
- **关系说明可以为空**（已确认）：空说明只保留连线本身，不渲染任何标签卡片；之后可以随时补写或修改。
  空说明不等于「未连上的线」，也不等于「有关系但没有说明」以外的第三种状态。
- **卡片折叠**（已确认）：带标题的卡片可以压成只留标题的一行，展开时恢复折叠前的高度。
  折叠不删除内容，不改变卡片的身份、位置与连线。带页头的媒体卡也遵守「折叠后只留可见页头可命中」；无页头的纯文本节点不提供折叠。
- 卡片引用内容 ID，不把资源树某个入口的位置当作内容身份。
- 原件交接后，卡片位置、尺寸、连线不变，更新归属提示，编辑入口跟随新归属。
- 笔记由用户选择放入画布，不自动把全部笔记铺上去。
- 资源树中的移动、增加引用或交接，不自动增删画布卡片。
- 卡片不保存第二份笔记正文；画布主要保存展示与关系数据。

## 7. Markdown 编辑与外部来源

### 7.1 自有笔记

- 无界与学习右栏复用同一个 Markdown 编辑器与保存者；两处快速编辑侧栏使用渲染编辑，不提供模式切换。文件标题下放常驻格式栏，正文直接铺在侧栏，不套绿色卡片，不重复「Markdown 正文」和「即时编辑」标题。
- 只有独立文档视图提供「预览／编辑／双列／渲染编辑」四种模式：预览只读；编辑显示完整源码和行号；双列左源码右实时预览，默认等宽且中间可调，窄屏保持双列模式但切换可见的源码或预览侧；渲染编辑提供局部标记显现和唯一格式栏。初次打开为渲染编辑，每篇独立记忆模式；模式切换不写正文、不丢草稿。状态恢复范围见 §2.2。
- 常驻格式栏支持正文／H1–H6、粗体、斜体、删除线、链接、列表、引用、代码和其他插入操作，窄栏可收纳次要操作。工具操作保留选区，适用操作在无选择时也可使用；撤销归正文编辑器，不借画布历史。
- 无序和有序列表的非活动项显示排版标记与层级；活动项露出真实源码。只读引用或旧格式库不能通过格式命令写入；中文输入与异步外部更新不得覆盖新草稿。
- 光标或选区触及的格式片段才显示真实、可编辑的灰色 Markdown 标记；内容仍保留粗体等排版，其他片段继续渲染，不将整段切为源码。正文自身的标题与内容不因去掉界面外壳而删除。
- 支持标题、列表、任务列表、代码块、表格、链接和公式；编辑文档以原 Markdown 字符串为真相，格式操作不通过全篇富文本序列化生成正文。仅打开、显隐标记、移动光标或换主题不改写原稿；未改动范围与换行保留。
- HTML、未支持的扩展语法保持原文可读，不执行或静默改写。新交互与首轮模式的验收状态分层见 §0 与 [ADR-0018](../adr/0018-共享Markdown局部编辑与格式栏.md)。
- 图片不自动访问外链，链接只在显式操作时打开安全 HTTP(S) 地址；不开放编辑器上传、CDN 或 AI 服务。大小超限拒绝修改，不截断正文。
- 支持通过外部编辑器修改正文，并检测更新。
- 提供打开正文文件或所在位置的入口。
- 外部修改与界面未保存内容冲突时，保留未保存内容并提示，不静默覆盖。
- 资源树改名、移动、归属交接在界面中完成；外部直接搬移或删除文件时，标记正文缺失，不猜测它的新位置或用户的组织意图。

### 7.2 课程节点

- 引用以来源工作区、科目 slug 与节点 ID 精确定位；添加时的名称只用于显示，不参与匹配。
- 拖课程节点到画布只添加引用卡，不移动节点、不自动铺入子笔记、不复制课件正文。卡片只有标题与跳转按钮，没有摘要或正文预览。
- 选中卡片时，侧栏只读呈现来源中的实际课件；跳转回准确的学习节点，保留无界画布。
- 来源失效时保留引用和原显示名，明确提示并允许手动重新关联；不按标题接到同名科目或节点，也不生成可编辑课件副本。

### 7.3 外部资源

- 网页可以直接粘贴 URL；本机外部文件通过显式选择添加。
- 只授权访问所选文件，不因添加一个文件就扫描其父目录或递归扫描其他文件。
- 默认只保存引用与描述，不复制原文，不自动采集网页。
- 首版至少能显示名称、类型并打开来源，不承诺所有格式的内嵌预览。
- 目标移动或失效时保留引用并提示，不悄悄删除入口。

## 8. 数据生命周期与保存

### 8.1 存放与身份

- 在 DSH 数据根下使用独立的笔记数据目录，不属于插件安装产物，不放进课件、作答数据或学习记录目录。
- 同一个 DSH 数据根内，笔记跨项目、跨档位可用；不承诺不同 DSH 数据根之间自动同步。
- 插件升级或卸载不主动删除笔记数据。
- 科目绑定只是关联，不决定笔记本存亡。
- 每篇自有笔记是真实 Markdown 文件；笔记本元数据、资源树、归属与引用关系、画布布局使用结构化文件保存。
- 界面文件夹是逻辑结构，不要求与磁盘目录一一对应。稳定 ID 定位正文，界面改名或交接不要求搬动正文文件。
- 数据目录可以整体备份。首轮目录名、文件布局与宿主存储接口定在 [ADR-0016](../adr/0016-无界笔记持久化与单文件版本栅栏.md)；备份与恢复流程仍未冻结。

### 8.2 自动保存与冲突

- 正文编辑与画布操作自动保存，显示「保存中／已保存／保存失败」等明确状态。
- 正文与画布分别保存，拖动卡片不能覆盖正文。
- 切换页面不能直接丢弃尚未保存的草稿。
- 同一份内容有版本冲突时，保留本地未保存内容，提示处理，不使用静默的最后写入获胜策略。
- 整理目录、交接归属和撤销同样需要考虑其他窗口的并发修改。

### 8.3 删除与恢复

- 从画布移除卡片，只移除该卡片及其连线，不删除原件。
- 删除引用只删除入口，不删除目标；任何外部资源操作都不能因此删除外部文件。
- 删除原笔记需从资源管理入口单独执行，并提示受影响的卡片或引用。
- 笔记、文件夹和笔记本采用回收站语义；删除笔记本时，其原件、内部目录与专属画布一起进入回收站。
- 其他位置的引用保留名称摘要和「来源已删除」状态；恢复原件后通过稳定 ID 恢复关联。
- 永久删除需要明确确认，并提示受影响的引用数量；不自动复制原文来掩盖来源删除。

## 9. 搜索与撤销

### 9.1 搜索

- 统一检索资源名称、引用别名、备注及自有 Markdown 正文。
- 支持限定当前笔记本或全部资源。
- 外部网页、本机外部文件与课程引用只搜索已保存的名称、地址和摘要，不扫描外部正文，不宣称搜索了完整课程库。
- 搜索结果区分原件与引用，并显示所在位置。

### 9.2 撤销与重做

- 首版支持当前打开期间的画布操作、目录移动、引用增删、归属交接及软删除撤销／重做。
- 正文使用编辑器自己的撤销栈；快捷键根据当前焦点作用，不能在写正文时意外撤销归属交接。
- 涉及对象已被其他窗口修改时，不强行回滚，明确提示冲突。
- 跨重启的完整操作历史不属于首版范围。

## 10. 权限与非目标

### 10.1 用户与 agent 边界

笔记是用户拥有的内容，不继承课件材料的 agent 写权限。首版不让 agent 自动读取、修改笔记或重排画布；只有用户显式选择并发送到会话的内容才进入相应会话上下文。以后若加入 AI 整理或写入，需要另行确定授权边界。

### 10.2 首版不做

- 手写、画笔、复杂图形、独立便签、分组框和嵌套画布；需要文字时创建 Markdown 笔记。
- 类似 Notion 的数据库、独立块级知识库和多人协作；即时 Markdown 编辑不再属于非目标。
- 网页自动抓取、全文抽取、外部资料批量扫描或向量检索。
- 将笔记本嵌套进笔记本，或让一本笔记本拥有多张画布。
- agent 自动读写笔记或自动安排画布。
- 跨重启的完整撤销历史。
- 让界面逻辑目录与磁盘文件夹强制一一对应。

### 10.3 安全边界（继承自原型，不放宽）

- HTML/SVG 静态媒体走 iframe 时 `sandbox=""`：**不执行 JavaScript、不加载外网资源**。
- 权限失败时**不发送缓存内容**——文件读取失败就当那次读取没发生，不退回上一次的内容冒充当前原件。
- 不递归读取目录；不写回用户选择的原文件。

## 11. 首版验收场景

以下是产品验收目标，不表示对应自动化套件已经存在。**#262 首个阶段只覆盖其中「画布与文档的交互」那一小截**
（独立网页 `scripts/tests/browser/notes_test.mjs`）；其余场景要等首轮持久化（#268）验收通过后才逐项成立。

| 场景 | 预期结果 |
| --- | --- |
| 创建未绑定科目的笔记本 | 创建成功，自动出现唯一专属画布 |
| 普通文件夹中创建笔记本 | 允许；笔记本内部再建笔记本则拒绝 |
| 创建笔记、放上画布并修改正文 | 只存在一份正文，列表与卡片预览同步更新 |
| 在 B 引用 A 的笔记 | B 可预览，编辑需打开 A 的原件 |
| 将 A 的原件拖到 B 已有引用处 | B 接任原件，A 留下引用，没有重复内容或重复入口 |
| 将 A 的原件拖到尚无引用的 B | B 建立原件入口，A 留下引用，其他引用不断链 |
| 拖动引用入口 | 仅移动引用位置，不改变原件归属 |
| 从公共资源区拖入原件 | 笔记本中建立引用，公共原件保留，不自动转移归属 |
| 整个文件夹交接归属 | 自有子树整体交接，内部外来引用不取得原件归属 |
| 创建直接或间接目录引用循环 | 拒绝并说明原因；异常已有循环不能卡死界面 |
| 交接一篇已上画布的笔记 | 卡片位置和连线不变，归属与编辑入口更新 |
| 移除卡片或删除引用 | 原件、课程文件与外部文件不被删除 |
| 删除并恢复来源笔记本 | 外部引用先显示来源已删除，恢复后重新关联 |
| 原课程节点失效 | 保留摘要和失效入口，不自动匹配同名节点 |
| 添加本机外部文件 | 只引用所选文件，不扫描父目录、不复制原文 |
| 两个窗口编辑同一篇笔记 | 版本冲突明确提示，不静默覆盖未保存内容 |
| 外部编辑器修改正文 | 能检测更新；与未保存正文冲突时保留双方内容 |
| 搜索当前笔记本 | 可查自有正文及引用描述，不宣称检索外部全文 |
| 撤销归属交接 | 在无并发冲突时恢复交接前关系，有冲突则拒绝强制回滚 |
| 切项目、切档位或升级插件 | 在同一 DSH 数据根内仍可访问笔记，不因安装产物替换丢失 |
