# StudyMate 目标态规格

> 状态：**目标态**，尚未实施。
> 定位：描述重构完成后系统长什么样——形状、数据、界面、闭环、门禁。
> 边界：**现行实现仍以 [设计方案](设计方案.md) 与 [工程约束](../规范/工程约束.md) 为准**；本文件落地后取代它们。为什么这么定见 [重构评估](重构评估.md)，先做什么见 [实施路线](实施路线.md)。
> 文中的 **[决定]** 是在调研访谈中明确拍板的；**[提案]** 是由那些决定推导出来、但本身没有被单独问过的部分——落地前需要维护者过一眼（清单见 §13）。

---

## 1. 一句话目标态

**StudyMate 从「提示词驱动的 Python 脚本引擎 + 一次性生成的静态页面」，变成「一个 DSH 插件包」**：Host 半用原生工具替掉全部脚本调用，Client 半用 React 阅读端替掉静态渲染，学习数据仍是工作区里的纯文本。

---

## 2. 系统形状

### 2.1 引擎就是一个插件包 [决定]

```text
@yunmiao/studymate/
├── lib/index.js            # Host 半：注册工具、服务、任务、路由、文件监听
├── lib/client.js           # Client 半：注册进宿主 slot 的 React 阅读端
├── preset/skills/          # 总控 + 5 角色 + 协议（唯一源，不变）
├── preset/learning/        # 「学习模式」预设源
├── schemas/                # 数据结构（不变）
└── locale/                 # 界面文案
```

- **Host 半**是 Node 侧的长驻进程，由 DSH 加载。它不受 agent 沙箱限制——这是暂存模式能被删掉的前提。
- **Client 半**是浏览器侧 bundle，用 `window.__ModuleLoader__.load()` 注册，向宿主 slot 注册 React 组件。
- **技能仍是唯一源**：`preset/skills/**` 同时供 DSH、Antigravity、Codex 三侧构建，构建期的断言式改写保留。

### 2.2 三区域模型保留，第二区域变薄 [决定]

| 区域 | 变化 |
|---|---|
| **引擎** | 从"一棵被拷贝的源码树"变成"一个已安装的插件包"。对 agent 仍然只读 |
| **用户级安装** | 仍写 `~/.dsh/studymate-config.yaml`（工作区定位）与「学习模式」预设；**不再往 `~/.dsh/studymate/engine/` 拷一份源码树** |
| **学习工作区** | 不变，仍是学习数据的唯一去处 |

安装入口仍是 `npx @yunmiao/studymate install`：注册预设 + 写配置 + 校验工作区，然后结束。

### 2.3 多宿主分档 [决定]

| 宿主 | 体验 |
|---|---|
| **DSH** | 完整体验：原生工具 + 阅读端 + 任务 + 按需导出 |
| **Antigravity / Codex·ChatGPT Work** | 无头路径：技能 + Node CLI，**默认导出静态页面**供学生阅读；没有阅读端 |

两端的适配**先维持可用、后单独演进**；本次不为它们设计新界面。

## 3. Host 半：工具与服务

### 3.1 工具清单 [决定 + 提案]

今天是"技能里写死命令 → 总控 bash 跑 Python 脚本 → 读 exit code"。新形状是**总控直接调用原生工具**，拿到结构化返回。

| 工具 | 替掉什么 | 返回 |
|---|---|---|
| `studymate.workspace.context` [提案] | 总控开场自己读一堆文件 | 工作区路径、时区与今天、科目清单（含当前节点与状态）、最近学习记录、可用能力 |
| `studymate_validate_curriculum` | 大纲／进度／科目档案的数据层校验 | 逐条问题（带文件与行号）+ 是否阻断 |
| `studymate_validate_lesson` | 课件内容层校验（格式 + 锚点四态 + 图片存在性） | 同上；DOM 结构检查退役（页面不再预生成） |
| `studymate_validate_pool` | 图片库校验 | 同上 |
| `studymate_validate_handoff` | 交接门禁 | 交接门禁结论 |
| `studymate_renumber_lessons` | 课件位次重排 | 重排结果（受影响节点清单） |
| `studymate_apply_empty_reasons` | 无题理由写回内容文件 | 打进了哪些锚点 |
| `studymate_export` | 工作区导出成自包含静态页面 | 导出的文件清单 |

> 表里的名字是**落地时的实名**：工具名用下划线不用点号（理由见 `decisions.md` §3——
> OpenAI 兼容接口的 `tools[].name` 只接受 `^[a-zA-Z0-9_-]+$`）。旧路径那一列在 #83 之后
> 已经没有对应的脚本了：Python 引擎整体退役，行为搬进了 `lib/**`。

三条约束：

- **工具的参数契约不塞进 system prompt**：常驻的只有一句工具说明，详细契约按需取（对齐调研结论 D4）。
- **越权即抛**：每个工具声明自己读哪些域、写哪些字段；未声明的读写直接报错，不靠文档约定（对齐 B1）。
- **模型能力缺失是协商结果**：没有可用模型时返回 `{available:false, reason}`，阅读端仍能读、能导出（对齐 B8）。

### 3.2 任务模型 [决定]

**范围**：任务模型只覆盖**插件自己执行的后台工作**——导出、资料格式转换、索引重建。
**不包括**"派角色生成内容"：那仍走 DSH 的子 agent 机制。两者在界面上统一呈现为进度条。

- 状态：`排队 / 运行 / 取消中 / 完成 / 失败 / 已取消`
- **状态查询从不阻塞**；等待有上限（默认几十秒）并在超时后给出明确的"下一步"提示
- 取消说清"哪些已完成的产物会保留"
- 销毁先回执、后删文件
- 状态**活着时在内存**；导出这类关键任务落盘，重开 DSH 能接上 [决定]
- 每个任务有 owner 标签；别人拿到的句柄访问不了它

### 3.3 文件监听与推送 [决定]

Host 半监听学习工作区，内容一变就通过宿主的 `/api` 通道推给打开的页面。

- 页面按"**未变即同引用**"更新：顶层键逐个比较，没变的直接沿用上一轮对象，避免击穿 memo 化的视图（对齐 F2）。
- 推送的是**变更通知**，不是整份数据；页面按需取自己要的那片。

## 4. Client 半：阅读端

### 4.0 落在宿主的哪里 [决定]

阅读端在宿主的 `main` 槽位注册**自己的 key**，靠侧边栏入口在中央区域与会话互相切换。

- `main` 是 `keyed` 槽位，**同一时刻只显示一个 key**；`conversation` 是宿主保留键，装着会话。所以阅读端与会话是**切换关系，不是同屏并排**。
- 切换入口挂在侧边栏；宿主侧不新增路由——阅读端**内部自己管路由**（主页 / 科目主页 / 课件阅读页 / 搜索）。
- 答疑不依赖会话可见：问答面板就地在课件页内回答（见 §7.4）；需要跟总控说话时从侧边栏切回会话。
- `sidebar` 与 `rightbar` 都已被宿主占用（都是 `single` 且已有 owner），插件只能往它们内部的**子座位**注册，不能整块占用。

### 4.1 信息架构 [决定]

**主页与科目主页单栏，课件阅读页三栏。** 中间栏分三级钻取；左右栏只在读课件时出现，且**默认收起**。

#### 壳

| 层级 | 布局 |
|---|---|
| 主页 | 单栏（中栏占满）+ 顶部面包屑 |
| 科目主页 | 单栏 + 顶部面包屑 |
| 课件阅读页 | **三栏**：左导航 / 中正文 / 右检查器，**左右栏默认收起** |

- **左栏**：当前科目的**节点树** + 四个附件折叠块（术语表 / 参考资源 / 学习记录 / 误解记录）
- **右栏**：`题目` / `问答` 两个 tab
- **点正文里的题目标记 → 右栏滑出并定位到那道题**：默认收起不抢正文宽度，做题时一步到位
- **两条栏的宽度可拖拽**，收起不丢宽度（规则见 §4.4）

#### 主页（单栏）

```text
主卡 · 接着上次     1 张，取最近改过进度的那门（progress.yaml 的 updated_at）
科目列表            全部科目一份；每行带进度细条与三档计数；已学完的折起来
```

**没有**"未完成的科目概览"（已并入科目列表）、**没有**"课程目录"（就是科目列表）、**没有**打卡与成就图（暂缓，见下）。

#### 科目主页（单栏）

```text
目录                按前置依赖分层的卡片 + 依赖连线；点卡片进课件阅读页
学生自加资料入口      写 reference/（见 §4.3）
```

#### 课件阅读页

```text
中栏 · 正文          含配图、公式、提示块；题目标记可点
左栏 · 导航          节点树 + 四个附件折叠块（默认收起）
右栏 · 检查器        题目 / 问答（默认收起，点标记滑出）
```

#### 常驻（哪一级都在）

```text
搜索                跨科目，覆盖五类内容（见 §4.5）
```

**没有"待复习"区块** [决定]：不做复习队列，也不做任何"今天该复习什么"的排期。

> **三处与早先决定的出入，记账在这里：**
> 1. 首页从「今天学什么」（一个启动器）改成「工作台」——早先的措辞作废。
> 2. **左右栏只在课件页、且默认收起**：早先定过"三级常驻"，被这条收窄。原因是主页中栏已经承载科目列表，常驻左栏会把同一份科目信息摆两遍。
> 3. **打卡与成就图暂缓** [决定]：两者都只由学习记录派生，而真工作区里四门科目的 `learning-records/` **全部为空**——现在做出来就是"0 天"与一片空白。要恢复它们，先给"哪天有学习活动"找到数据源（作答数据带时间戳，或阅读端记一条"打开课件"的活动），再谈。这条同时把早先「状态只服务当场回顾，不做任何汇总视图」的规则原样保留。

> **一处副作用，记账在这里**：四个附件折叠块只在课件页左栏可见，所以**在科目主页看不到本科目的术语表与参考资源**。这是"科目主页只管目录与加资料"换来的代价；如果实际用起来别扭，把它们提到科目主页即可（改动很小）。

### 4.2 组件与样式来源 [决定]

按 DSH 官方插件规范：**把宿主原语的标记、CSS 与行为抄进插件**，类名换成自己的前缀，颜色只引 `--dsw-alias-*` token。

- 不 import 宿主的客户端包（会随宿主版本变化、无类型检查、组件抛错会清空 slot）。
- 现有的自研 Sayo UI 不移植；页面模板与那套前端资源随静态渲染一起退役（#83 已删）。
- **token 纪律写成测试**：解析 token 块 → 算相对亮度 → 断言每个文本 token 在每个表面上都达 WCAG AA，亮暗两套都测（对齐 F8）。

### 4.3 数据流 [决定]

| 方向 | 谁写 | 机制 |
|---|---|---|
| 学习内容（大纲、课件、题库、进度、档案） | **只有 agent**（总控与角色） | 写文件；Host 半监听到变化后推送 |
| 学生自加的参考资料 | **只有阅读端** | 前端 → Host 半 → 写 `reference/`；同样的幂等与版本号保护 |
| 作答数据 | **只有阅读端** | 前端 → Host 半 → 落盘；幂等（`operationId`）+ 版本号（`expectedVersion`）冲突拒绝 |
| 索引 | 前端内存 | 按需扫描工作区，不落盘 [决定] |

**两条写入路径，范围不重叠**（早先的"前端不写任何学习内容"已作废，见 [ADR-0010](../adr/0010-阅读端可直接写参考资料.md)）：

- 阅读端能写的**只有两处**：`reference/`（学生自己加的资料）与作答数据。**其余一律不写。**
- 学生加的资料必须**带来源标记**：与角色收的资料同放 `reference/`，日后要能分清哪份是人放的、哪份是资料收集角色收的。
- 路径越界一律拒绝（沿用 `lib/assets.ts` 已有的取址越界拒绝做法）。
- 冲突时**拒绝写入并重读**，不引入文件锁（对齐 B3）。
- 陈旧响应不许覆盖新作答：写队列 + 合并轮询 + 明确的栅栏（对齐 F3）。

### 4.4 关键交互

| 交互 | 做法 |
|---|---|
| **阅读位置恢复** | 捕获 `{sectionOffset, scrollTop, progress}`，恢复按 section → offset → progress 三级降级（对齐 F4） |
| **锚点定位** | 正文的 `::: quiz` 锚点与题库键对接，定位结果分四态：`resolved / stale / ambiguous / missing`；多匹配绝不静默取第一个（对齐 F5） |
| **点题目标记** | 正文里的题目标记可点 → 右栏滑出并定位到那道题（右栏默认收起，见 §4.1） |
| **从选中发起提问** | 选中正文 → 右栏的「问答」tab 滑出 → 面板独立调模型回答（见 §7.4） |
| **首次引导** | 定位几何是纯数学：优先方位 → 按剩余空间换边 → 窄容器停靠底部 → 目标占满时退到内角（对齐 F6） |
| **无障碍** | 图表用 `aria-label` + 视觉隐藏的 `<table>` 兜底；进度条是真 `role="progressbar"`；动效分 `auto/full/reduced/off` 四档（对齐 F7） |
| **栏宽拖拽** | 左右栏的边缘可拖动改宽（规则见下） |

**栏宽拖拽** [决定]：

- 两条栏的边缘各有一条**拖拽把手**；拖动改宽度。**收起只是隐藏**——再展开回到上次拖的宽度，不回到默认。
- 宽度**全局各记一份**（左栏一份、右栏一份），与主题、动效档同属浏览器本地偏好；换科目、换层级都不变。
- **拖拽写入按当前画布宽度 clamp**；画布变窄时自动让步（收起），但**绝不覆写已存的宽度**——画布变宽后自动恢复。

> 后两条抄自宿主：`dsh-client-ui-layout` 的 `stores.d.ts` 写明 *Drag writes clamp to the current frame's range* 与 *Responsive concessions never rewrite widths*（后者还注明是刻意的）。宿主对两条栏的收起语义并不一致（侧边栏收起即忘宽度，右栏保留），**我们统一取"保留"**。

- 无障碍：把手是 `role="separator"` + `aria-orientation="vertical"` + `aria-valuenow / aria-valuemin / aria-valuemax`；聚焦后用方向键调宽。
- [提案] 双击把手恢复默认宽；收起状态下把手仍在（拖一下即展开）。这两条没有被单独问过，落地前过一眼。

### 4.5 搜索索引覆盖 [决定]

跨科目内存索引，覆盖五类：

1. 课件正文（标题 + 全文）
2. 题库（题干 + 选项）
3. 各科术语表（规范叫法与别名）
4. 学习记录与误解记录
5. 大纲节点元信息（`objective` / `problem` / `pitfalls`）

索引是**派生物**：丢了随时重建，绝不成为第二份真相。

## 5. 学习数据模型

### 5.1 布局：保留、退役、新增

```text
<学习工作区>/
└── .learning/
    ├── MEMORY.md                       # 共享记忆（保留）
    └── subjects/<slug>/
        ├── subject.yaml  MISSION.md  RESOURCES.md  GLOSSARY.md   # 保留
        ├── curriculum.yaml             # 保留
        ├── progress.yaml               # 保留，词表精简为三档
        ├── misconceptions.yaml         # 保留，重新设计为单一落点
        ├── lessons/<NNNN>-<节点id>.md          # 保留
        ├── lessons/<NNNN>-<节点id>.quiz.json   # 保留，保持纯净
        ├── attempts/<NNNN>-<节点id>.json       # 新增：作答数据
        ├── lab/  sources/  assets/             # 保留
        ├── reference/                  # 保留；**阅读端可写**（学生自加的资料，见 §4.3）
        ├── learning-records/           # 保留；实验课验收结论也写这里
        ├── assessments/                # 退役：不再产生新文件，旧文件保留可读
        ├── sessions/                   # 退役：同上
        └── lessons/*.html  index.html  # 退役：页面由阅读端实时渲染
```

- **`assets/` 里的科目组件副本退役**：`style.css` / `quiz.js` / `lesson-toc.js` 不再往每个科目拷一份——渲染与判分都在阅读端。
- 工作区根 `index.html` 与科目 `index.html` 不再生成；需要离线阅读时走导出（§8）。

### 5.2 进度：三档，取消掌握度 [决定]

- 词表：**未开始 / 学习中 / 已学完**
- `mastery` 字段删除
- **读取旧工作区时自动映射**：未开始→未开始；学习中、初步理解→学习中；能独立应用、需要复习、已通过项目验证→已学完
- 写回一律用新词表；旧文件不强制改写，下次写盘时自然收敛

> 这是 [ADR-0004](../adr/0004-学习数据格式冻结与例外.md) 里那条**唯一例外**：布局与文件名冻结，状态词表明确变更。

### 5.3 作答数据独立存放 [决定]

`attempts/<NNNN>-<节点id>.json`，与课件一一对应。

- **题库保持纯净**：`.quiz.json` 仍是模型写的课件内容文件，锚点与正文逐字对应；作答历史绝不写回它，避免模型与前端共写同一个文件。
- 每题带 id 与状态：作答历史、错因、上次结果。
- **状态只服务"当场回顾"** [决定]：在课件页里就地显示（"上次你选了 B"），不做任何汇总视图、不排期、不算复习队列。

### 5.4 误解记录：单一落点 [提案]

今天 `misconceptions.yaml` 与 `progress.yaml` 的 `misconceptions` 是双落点。新设计**只保留 `misconceptions.yaml`**：

| 字段 | 含义 |
|---|---|
| `topic` | 卡在哪 |
| `source` | 从哪来：问答面板 / 讲解反馈 / 实验课验收 |
| `evidence` | 证据：提问原文、作答引用或验收结论 |
| `status` | 未处理 / 已补练 / 已消解 |
| `at` | 时间 |

理由：双落点是为了让进度文件自包含；进度已精简为三档，重复存储只会带来不同步。

### 5.5 开场恢复靠三份文件 [决定]

`progress.yaml`（学到哪、什么状态）+ `MEMORY.md`（学生画像）+ `learning-records/`（真的学会了什么）。

**开场不再读任何"上次会话"记录**——会话摘要退役。

## 6. 学习闭环

### 6.1 一次会话

1. **开场**：总控调 `studymate.workspace.context` 拿摘要 → 报"上次学到哪、这次建议学什么" → 打开阅读端
2. **新科目**：盘问 → 派角色 → 工具校验 → 阅读端**自动出现**（无需刷新）
3. **学一个节点**：派讲解写内容文件 → 工具校验内容格式 → 派角色出题 → 工具校验锚点对账 → 学生在阅读端打开课件
4. **作答**：三轨判分（§7）
5. **局部提问**：问答面板（§7.4）
6. **实验课**：验收（§7.3）
7. **收尾**：更新进度（三档）、误解记录、学习记录——**没有"渲染""搬运""刷新主页"这三步了**

### 6.2 相对今天的简化

| 今天要做 | 目标态 |
|---|---|
| 开场 0.5 步定暂存工作区 | 删除 |
| 收尾问落点、`cp -a` 搬运、写 `prefs.md` | 删除 |
| 渲染页面 → 查 DOM 两段式 | 删除（渲染在阅读端，校验查数据） |
| 刷新主页这一步 | 删除（文件一变，阅读端自己更新） |
| 派工前算 `md5` 基准比对改动 | 删除（版本号由工具管） |
| `.stage/` 暂存交接 + 交接门禁 | **保留**：这是产物层门禁，与写盘权限无关 |

## 7. 层级、题型与判分

### 7.1 四层重定义 [决定]

| 层 | 含义 | 通过标准 |
|---|---|---|
| **读懂** | 能解释为什么，不只给结论 | 说清因果与前提 |
| **改对** | 改一处并**先预测**结果，再跑起来验证 | 预测与实测一致，或能解释差异 |
| **查错** | 定位真实 bug 的根因 | 说出根因 + 修复 + 预防 |
| **造出** | 从零做出可运行的东西 | 交付物能跑通 + 能解释取舍 |

- **取消"课型限层级"** [决定]：深度由节点的 `objective` 决定，不再由课型决定。
- **课型只决定产不产 lab 材料**：`概念` 不产 lab，`实操` 产当课 lab，`实验` 产里程碑任务。

### 7.2 题型

| 题型 | 服务哪一层 | 判分 |
|---|---|---|
| 客观题 | 读懂 | 页内自动判 |
| 预测 + 验证 | 改对、查错 | 先写下预测，再跑起来对照 |
| 开放题 | 读懂（说清为什么）、查错（找根因） | 展开参考答案与判分要点，学生自评 |
| 交付物 | 造出 | 可运行证据（测试 / 断言 / 期望输出） |

**评估题取消**（阶段评估已删，见 §7.3）。

**题目不在正文流里就地展开**：抽到右栏的「题目」tab，正文只留可点的编号标记（见 §4.1）。读正文时右栏收起，不抢宽度。

### 7.3 判分三轨，全在阅读端完成 [决定]

| 轨道 | 谁执行 | 落到哪 |
|---|---|---|
| 客观题 | 阅读端即时判 | 作答数据 |
| 主观题 | 展开参考答案 + 学生自评 | 作答数据（含自评） |
| 实操题 | **Host 半代跑**学生本地的测试命令 | 作答数据（含真实输出） |

**没有任何一轨叫 agent。** 三轨都不产生"你会了"的结论，只产生事实与自评。

### 7.4 问答面板 [决定]

- 阅读端选中正文 → 面板就地打开 → **面板独立调模型回答**，不经过总控。
- 上下文只带：当前课件、选中文本、共享记忆。不背整个会话。
- **回答无痕，但写一条误解记录**：提问原文 + 回答摘要 + 位置进 `misconceptions.yaml`，总控下次开场读得到。

> 这条破例于现行硬规则「与用户交互只有总控」（见 [重构评估 §5](重构评估.md)）。总控仍是学习对话里唯一的对话对象；面板是**阅读端的就地答疑入口**，不承担盘问、确认与调度。

### 7.5 实验课验收：保留 [决定]

- **阶段评估删除**（每 3–5 节点一次的那个节拍没了）；**实验课验收保留**，仍由 `practice-evaluator` 做。
- 验收依据按证据可信度排序（运行结果 > 学生自写的测试 > 解释能力 > 口头确认），并叠加**证据资格政策**（对齐 D1）：
  - 延迟重测才算独立证据
  - 明确列出**不能算独立通过证据**的东西：自评、同日重试、关键词标签、仅浏览过
  - 分母口径明确：全部必需核心点；范围为空时绝不显示"通过"
- 结论写进 `learning-records/`，`assessments/` 不再产生新文件。
- **模型输出不能直接改进度状态**（对齐 D2）。

## 8. 导出

- 工具 `studymate.export` 把学习工作区渲染成**自包含的静态页面**。
- **DSH**：按需——学生说"导出一份能离线看的"才跑 [决定]。
- **Antigravity / Codex**：**默认导出**，课完就导一份 [决定]。
- 导出产物必须**不引用任何只存在于 Node 的东西**：构建期加一道泄漏守卫，泄漏就让构建失败（对齐 F11）。
- 导出是**能力**，不是架构主线：阅读端才是主体验。

## 9. 角色与协议

### 9.1 五个角色保留，职责清洗 [决定]

角色数量与名字不变；变的是"活"。

| 角色 | 保留 | 清洗掉 |
|---|---|---|
| 资料收集 `resource-scout` | 外部检索、来源转 Markdown | 一切"环境准备"的自述 |
| 采图 `image-scout` | 抓图、落图片库与索引 | 同上 |
| 课设 `curriculum-designer` | 大纲 DAG、实验课节点 | 同上 |
| 讲解 `learning-coach` | 写课件内容文件与速查页 | 同上 |
| 出题评估 `practice-evaluator` | **出题** + **实验课验收** | 阶段评估（已删）；`assessments/` 撰写 |

**总控的机械步骤全部消失**：不再跑脚本、看 exit code、`cp` 搬运、算 `md5`、管暂存区；改为调工具、读结构化返回。

### 9.2 协议增删

| 协议 | 处置 |
|---|---|
| `learning-discovery` | 保留 |
| `lesson-design` | 保留（课件的唯一约束来源） |
| `layered-practice` | **改写**：新四层、新题型、取消评估题、课型不再限层级 |
| `evidence-check` | **收窄**：只服务实验课验收 |
| `local-qa` | **改写**：问答面板就地回答；误解记录改单一落点 |
| `record-keeping` | **改写**：三档进度、删暂存模式、删 `sessions/` 与 `assessments/`、新增作答数据的只读视角 |

### 9.3 技能瘦身

技能里的常驻指令要压下来（对齐 D4）：**参数、路径、命令、格式全部从技能里消失**——它们要么进了工具契约，要么进了 schema。技能只留"这件事为什么要做、做到什么算好"。

## 10. 门禁与测试

### 10.1 三层门禁 [决定]

| 层 | 查什么 | 怎么跑 |
|---|---|---|
| **数据层** | `schemas/*.json` 校验、引用完整性、大纲 DAG 无环与位次不倒挂、实验课前置非空 | 工具，可在会话里跑，也可在 CI 跑 |
| **内容层** | 内容格式解析、锚点与题库逐字对账、图片存在性、公式标记 | 工具 |
| **渲染层** | 拿一份临时科目真渲染一遍（冒烟） | 测试里跑 |

### 10.2 测试数据：测试时现造 [决定]

**删掉 `examples/`**。测试在临时目录现造一份最小科目（两三个节点、一课、几道题），跑完即弃——仓库里不存样例数据，也不会腐坏。

### 10.3 保留并强化的门禁

| 项 | 说明 |
|---|---|
| 门禁覆盖断言 | `scripts/tests/` 下未登记的套件直接让门禁失败（对齐 A1） |
| 测试运行器 | 清洗环境变量、一次性 HOME、网络守卫（对齐 A2） |
| 架构边界测试 | 用真实 import 图断言不许跨域 import，并断言依赖图无环（对齐 B2） |
| 对比度测试 | 每个文本 token 在每个表面上都达 WCAG AA，亮暗两套（对齐 F8） |
| 浏览器 QA | 找本机已装的 Chromium；每个用例出截图集 + `summary.json`（控制台错误、页面错误、失败请求）（对齐 A4） |
| 性能预算 | 写成"相对工作区规模的比例"，不写绝对秒数（对齐 A5） |

### 10.4 退役的门禁

示例工作区与前端资源的逐字节比对、渲染产物的 DOM 结构检查、Python 语法检查、模板占位符契约检查——全部随静态渲染一起退役（#83 已执行）。

## 12. 非目标

| 不做 | 理由 |
|---|---|
| 音频、转写、字幕、直播课堂 | 需外部付费服务与密钥管理；与"应用技能专攻"关联弱 |
| 正文级逐字引用与来源校验 | 收益与成本不成比例；引用需求由图片级来源与「资源清单」覆盖 |
| 向量检索 / 嵌入索引 | 工作区是纯文本、体量小，按需扫描足够 |
| 间隔重复、复习队列、任何"待复习"汇总 | 不做应试专攻 |
| 独立 Web 应用（脱离 DSH） | 阅读端只做 DSH 客户端插件 |
| 免费 / 付费分层、用量统计 | 无商业化计划 |
| 多用户、账号、云同步 | 现状即单机单用户 |
| 在线代码编辑器 | 用本地文件与终端 |

## 13. 本规格中新提出的部分（落地前需过目）
