# 无界笔记 · 网页开发与验收入口

这个目录是**保留下来的网页入口**：开发画布/文档交互，以及在没有宿主的前提下做自动化验收。
它不是第二个交付形态，也不是完成品——**本网页入口无持久化适配，笔记只在本页内存里，刷新即重置**；正式 DSH 入口的持久化状态以[无界笔记设计](../../docs/设计/无界笔记.md) §0 为唯一出处。
不要在这里保存真实笔记的唯一副本。

组件源码**不在本目录**：唯一源码在仓库根的 [`client/notes/`](../../client/notes/)，
宿主适配在 [`bridge.jsx`](../../client/notes/host/bridge.jsx)。本目录保留 `index.html`、`vite.config.js` 和手写示例等薄入口文件，组件与依赖均从仓库根复用。形状上的决定见
[ADR-0015](../../docs/adr/0015-无界笔记模块与独立数据域.md)，工程约束见
[工程约束](../../docs/规范/工程约束.md) §二「客户端单入口与无界笔记的构建」。

## 跑起来

在仓库根执行（前端与构建工具统一锁在根 `devDependencies`，Host 无运行时依赖）：

```powershell
npm ci --ignore-scripts
npm run dev:notes            # 开发服务：http://127.0.0.1:4178/
npm run build:notes:preview  # 构建 dist/notes-preview
npm run preview:notes        # 预览已构建的产物（同一端口）
npm run test:notes:browser   # 构建后在独立 Edge 验收
```

不要同时起两个进程占 4178。源码改动后要重建再看；不承诺热更新。

验收与检查的入口名（`build:notes:preview`、`dev:notes`、`preview:notes`、`test:notes:browser`）由
[工程约束](../../docs/规范/工程约束.md) §二「脚本名」定义，各命令的前置归
[测试说明](../../scripts/tests/README.md)。

## DSH 里的入口

正式客户端在现有「学习」面板里切换学习与无界笔记，使用顶栏品牌按钮，不另设无界笔记侧栏项；品牌文案、图标与状态保持判据见 [阅读端呈现](../../docs/规范/阅读端呈现.md) §九。本网页只验收共享组件，不假装自己有 DSH 侧栏或真实会话。

旧实验客户端已通过宿主官方命令卸载，临时编译兼容产物也已清理；不再保留第二份原生入口。

## 会话在这里是占位

页面右侧的对话区是**占位组件**：它显示「未连接会话」，发送不可用，不请求模型、不选择会话、不复制凭据，
也不会自动新建或发送任何消息。它的存在是为了让画布布局与拖拽引用在纯网页环境里也能被验收。
**占位只到这一页为止**：在 DSH 里，正式入口经 `client/notes/host/bridge.jsx` 继续复用已验证的原生会话适配
（显式选现有会话、引用只进草稿），不退回占位。本轮不做真实消息发送的验收。

## 本版界面与操作

- **壳层与主题**：明暗两套都是中性色；侧栏、顶栏为一层，画布与编辑器更深一档。独立页默认跟随系统并可切换本画板主题。界面声明 `color-scheme`。
- **点阵**：点距与圆点直径都使用**画布坐标**（间距 24 画布单位），缩放时点阵与卡片、连线一起放大缩小；不再把间距钉死在屏幕像素上。
- **侧栏**：左侧文件栏和右侧面板的展开、收起都有宽度与位移过渡；动画变量定义在画板根元素上，与明暗主题无关。系统启用"减少动态效果"时整段关掉，拖宽时暂停过渡以跟手。左栏收起后留一条窄轨恢复；右栏的恢复开关固定在顶栏最右侧。两侧边界都可拖宽，也支持方向键。
- **画布交互**：默认拖动整张卡片；双击卡片进入选字阅读，双击纯内容节点进入编辑。带标题的卡片可用标题右侧的折叠箭头压成**仅标题的一行**；展开恢复折叠前高度，折叠/展开都进画板撤销历史。折叠后节点只保留可见页头的命中区，旧正文位置不再留下可拖动的透明区域，静态页和图片卡片也遵循此规则；无页头的纯文本节点不提供折叠。卡片正文滚轮只滚卡片，空白画布滚轮仍可缩放。**静态页 / SVG 卡片在 iframe 内可滚动**；此时从页头拖动整卡，图片卡仍按整卡拖动。按住 Space 拖动总是平移视口；保持 Space 时滚轮仍可缩放。`V` 选择，`H` 平移，`1` 适应画布。
- **共享 Markdown 正文**：独立文档可选预览、编辑（完整源码）、双列、渲染编辑；窄屏双列只切换可见侧，不退出该模式。右侧详情只提供渲染编辑：标题下有一条格式栏，光标触及的片段才露出真实、可修改的标记。详见[文档视图与 Markdown 编辑](../../docs/设计/无界笔记.md#7-markdown-编辑与外部来源)。
- **格式与原稿**：格式操作在原 Markdown 上修改，不对全篇重新排版。未操作的字符与换行保留；仅移动光标、显隐标记、换主题或切视图不改写正文。
- **右侧详情**：切到画布时，右侧标题栏集中放定位/放到画布、打开文档、移出画布三个动作。移出画布只删卡片和相关连线，**文件保留**在左树。
- **网页链接**：网页引用在画布上是**无页头的文本节点**，整块可拖动、只读。标题是真实 http(s) 链接，下面显示主机名和已存描述；不复制网页正文，也不自动抓取页面。
- **关系与撤销**：节点圆点之间拖动建立关系。关系说明**可以为空**：空说明不渲染任何标签卡片，只保留线条本身；双击线条可随时添加或修改，Enter 确认、Esc 取消。画布 50 步撤销/重做，正文编辑使用 CodeMirror 自己的撤销历史。
- **帮助与快捷键**：顶栏 `?` 打开"操作说明"，内含画布、导入、编辑布局、安全保存的分组说明与快捷键表。常用键：空格 + 拖动强制平移，滚轮或空格 + 滚轮缩放，`H` / `V` 切换平移/选择，`1` 适应全部节点，Shift + 点击多选，Delete / Backspace 删除所选并保留文件，`Ctrl/⌘ + Z` 撤销、`Ctrl/⌘ + Shift + Z` 重做，Esc 退出编辑或关闭弹窗，纯内容节点内 `Ctrl/⌘ + Enter` 提交。

## 导入、副本与文件引用

- 左侧文件栏标题栏的 **导入** 图标提供两项菜单：**副本** 直接选本地文件；**引用** 先选来源——本地文件，或网页地址。
- **外部文件拖入画布**时先选择副本或引用，再放入卡片。副本保留外部文件名，内容有独立资源 ID；引用仍指向原件，不写回外部文件。
- **从左侧资源树拖入画布**只建立引用，不弹出导入选择；已有该原件的卡片则直接定位。要复制正文，使用 Markdown 行的「⋯ → 复制 Markdown」。副本在同目录生成，不继承课程关联，也不自动放到画布。可读取的外部 Markdown 引用也可复制。
- **本地文件引用是只读的**：不提供改名或写回原件。Markdown 文档可在编辑或双列模式查看只读源码。浏览器提供文件句柄（`FileSystemFileHandle`）时，打开或选中引用可重新读取文件；右侧详情也提供「重新读取引用」。
- **File-only 环境**：浏览器不提供文件句柄时，只保留本次选中的文件，并明确标出"本环境只能使用本次选中的文件"。不监听原件变化，原件改了要重新选择；这类引用只在本次页面生命周期内有效。
- 不递归读取文件夹，拖入目录会明确报错。每批最多 12 个文件，失败的文件进入"部分文件未导入"清单，成功的照常导入。

## 静态媒体的安全边界

支持 PNG、JPEG、WebP、SVG、HTML。HTML/SVG 只作保守的静态预览，**不执行 JavaScript，不自动加载外部资源**；iframe 沙箱为空（无任何权限）。
`examples/static-page.html` 是可直接用"导入 → 副本"打开的手写静态页面示例，只有 HTML、CSS 和内联 SVG，没有脚本或外部资源。

| 范围 | 限制 |
| --- | --- |
| 单张栅格图 | 4 MiB、任一边不超过 8192、总像素不超过 1600 万 |
| SVG | 512 KiB、2000 个元素、深度 32、累计 path 数据 100000 字符 |
| HTML | 256 KiB、1500 个元素、深度 32；内部 SVG 同时受路径和深度限制 |
| 内嵌图片 | 仅验证后的 PNG/JPEG/WebP data 图片，每份最多 64 张、累计 1600 万像素，重复也计入 |
| 单批 / 本页 | 每批 12 文件；媒体总量 32 MiB，250 资源，120 节点 / 240 连线 |
| 文本 | Markdown 128 Ki 字符；纯节点 8000 字符；关系标注 60 字符 |

先检查栅格格式头、尺寸和动画标记，再解码。HTML 用 inert template，SVG 用 XML，清理脚本、事件、外部资源、动画、高开销滤镜等。限制不是对任意网页还原或所有性能风险的保证。
**权限失败时不发送缓存内容**：读取失败就当那次读取没发生，不退回上一次的内容冒充当前原件。

## 继续开发

- 改交互就改 `client/notes/` 里的源码；本目录只保留网页入口与构建配置，不放第二份组件。
