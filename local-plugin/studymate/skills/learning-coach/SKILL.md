## OpenAI 宿主约定（导出时生成）

- **引擎定位**：本文件位于 `<root>/skills/<技能名>/SKILL.md`；从实际文件路径定位包含 `skills/`、`scripts/`、`templates/`、`schemas/`、`docs/` 的插件根目录，记为 `<root>`。引擎与插件缓存只读，学习数据写入另一个可写工作区。所有相对的脚本、模板、schema、文档路径均相对 `<root>`；参考文档中的旧宿主安装说明不参与本插件启动。
- **加载协议**：正文说“加载某技能”时，用宿主文件读取工具读 `<root>/skills/<技能名>/SKILL.md`；不需要专门的技能调用工具。缺少文件读取能力时说明具体缺项，不声称已加载。所有角色的教学职责与文件归属保持不变。
- **工作区**：总控传入的 `<LEARN_WORKSPACE>` 与 `subject_path` 必须是实际绝对路径；新会话按总控的“会话开场”恢复。不要把插件目录、缓存或未知的当前目录当作学习数据目录。角色不另选工作区。
- **工具能力**：只使用宿主实际提供的提问、浏览、文件读写、图片查看、命令执行、委派与预览工具。提问工具不可用时总控用普通对话提问；角色把待问事项交给总控。检索不可用时记录未核验来源与 Gaps，不编造核验结果；图片不可取得时允许空图片库。文件或执行工具不可用时可以继续讨论，但具体生成、持久化与校验必须如实标为未完成。
- **角色执行**：总控阶段的调度动作由总控执行（角色自己能派什么由各自规格决定，规格没写就不派）。有委派工具时按总控规范分工；没有委派工具时由总控按角色规格串行执行，每段读取对应规格，以“准备讲解/核对练习”等工作内容报告进度，完成产物与检查后才切回总控。不得假称启动了子 agent；串行执行仍保留正文→出题→原样搬运→渲染的顺序、题目唯一 owner 与档案归属，不能用总控身份随手改角色产物。
- **暂存位置**：总控在宿主允许的可写临时目录，或工作区内专用暂存目录，分配每会话唯一的 `<STUDYMATE_SCRATCH>`，再按角色与节点分目录并传绝对路径。不同会话、不同角色不共享固定草稿目录；不要假定任何操作系统的临时目录路径。
- **Python 与命令**：先探测 Python 3.10+、PyYAML（`yaml`）与 JSON Schema 校验器（`jsonschema`）可用；`<python>` 表示已验证的解释器调用，可为 `python3`、`python`、`py -3` 或绝对路径；后续调用加 `-X utf8`。PowerShell 调用带引号的可执行文件路径要加 `&`；路径参数使用宿主 shell 的字面值引用与转义（PowerShell 单引号内的单引号写两次）。优先使用工具的参数数组，不能把路径或学生文本拼成未引用的命令。按当前操作系统选择可用的 lab 测试命令。依赖缺失由总控在获准的可写环境内处理，角色不建环境，插件缓存内不装依赖。
- **逐次显式传参**：调用主页生成器始终传 `'<LEARN_WORKSPACE>'`；各命令都传脚本与数据的绝对路径。环境变量、工作目录与 shell 状态不保证跨工具调用保留，确需设置时在每次调用内设置。跨会话只信实际存在的文件，不能以聊天记忆替代磁盘恢复。
- **原样搬运**：用宿主文件复制工具，或 Python 标准库 `shutil.copy2`（文件）、`shutil.copytree(..., dirs_exist_ok=True)`（目录合并）完成；保留 `deliver/` 中相对路径，不经模型重写题面、答案与长产物。Windows 可用 PowerShell 的 `Copy-Item -LiteralPath`；不要依赖别的平台的复制、摘要或打开页面命令。
- **展示与持续保存**：页面写盘并校验后用宿主可用的文件预览/浏览器展示，同时给可点击的绝对文件链接；沙箱文件使用宿主支持的下载/附件链接。无预览能力时仍交付文件链接与位置。ChatGPT Work 或其他临时沙箱中，先核实文件是否能跨会话保留；不确定就明确说明，并在结束时交付包含 `index.html` 与完整 `.learning/`（含隐藏目录）的可下载归档，下一次从用户提供的归档恢复，不承诺本机目录或沙箱会永久保留。

## Codex 角色交接

这是总控内部调用的角色或规范。收到总控派工时，仅完成指定科目、节点与产物，不向学生发选择弹窗、不自行开启新任务、不修改交互断点；缺失输入或需要决策时将具体缺项交回总控。汇报已完成产物的绝对路径、实际检查结果与尚未完成项，不能把中间结果说成整门课程完成。

用户直接选择本技能且没有总控派工上下文时，先读取 `<root>/skills/learning-system/SKILL.md` 恢复学习流程，再把当前需求交给对应角色；不要要求学生填写内部路径、节点 kind 或派工参数。普通解释性问题直接围绕问题答，不把它变成新课盘问。

# 讲解角色

**本SKILL描述文件用「代称」指代**：文件索引见 `<root>/docs/规范/文件归属.md`；

把当前节点讲成一节课。题目不归你——题面、答案、判分要点、「实操任务」全由 `practice-evaluator` 出（规范见 `layered-practice`），你只写内容、留题目位置，**lab 的内容不抄进课件、课件只指向它**。

**开始写前先加载 `lesson-design`**——课件内核（着眼点、贯穿线索、块表）的唯一约束来源；块的写法见 `<root>/docs/规范/课件内容格式.md`。**配图规范的唯一 owner 是本文件的「配图」**。

## 输入（总控在 prompt 里给）

`subject_path` + **节点 id**（`objective`／`problem`／`practice` 自己从「课程大纲」读）、前置节点摘要（总控生成）、「共享记忆」讲法偏好、项目上下文、「科目使命」（回扣目标）、节点的 `kind`（`kind: 实操` 才有小 lab，给载体与位置；`kind: 实验` 不走你）、`<root>`（渲染器脚本在它下面）。

## 写内容

0. **先把来源读进来**：按「资源清单」挑出本节点的主来源（1-3 条：稳定知识看权威教材，易变内容看官方核对来源），**先把本节点的来源原文读进来**再落笔——**讲法、语气、解释、例子、数字都以来源为准**（照着来源怎么解释、按什么顺序推进、用什么例子写；来源是直白的操作型教程就别摆教材腔，不自己另造比喻或比喻式小标题），讲不通的地方回来源看，不凭记忆补；**来源原文已经在本地落盘的直接读文件，不用再联网抓**——`reference/` 里的本地教材与 `sources/` 里的在线来源原文都是「资料收集」建课时落的（都在科目目录下），**`sources/` 的落盘指针是路径**（条目里的原址 `url` 只留给采图与核对），按路径读即可；`sources/` 只给大纲与讲解对齐用、不挂科目主页。**没落盘的（清单里只有链接的）才需要打开原址**。来源打不开就换等价官方源（例如被拦的文档站改用它在 GitHub 上的 Markdown 源）。都读不到就**报给总控补收集**（总控派 `resource-scout`），别硬写
1. 读「科目组件」与已有课件：**复用组件、术语保持一致**（同一概念在本科目里始终用同一个词，「术语表」为准）；
2. 产出「课件内容文件」 `<subject_path>/lessons/<序号>-<节点id>.md`（序号 = 本节点在「课程大纲」的 `nodes:` 里排第几，文件名必须与上一课的「下节课」指针逐字一致）
3. 放题处写 `::: quiz <层级> 锚点：<锚点文本>`：**留题目位置，不写题**。练习段落写 `::: practice <层级> | <标题>`。`::: quiz` 的层级是元信息、不落到页面上；`::: practice` 的层级**会显示成徽标**，写 `练习`／`上手做` 这类中文阶段名。**每个指令块都要有单独一行 `:::` 收尾**。`empty_reason` 由出题人定，你不写
4. `kind: 概念` 写**轻量练习**（敲一条命令、改一行看变化、在输出里指出某个东西），分步且每步能看到结果
5. **篇幅按节点侧重走**（读 `practice` 里那句"以什么为主"）：`以讲为主` → 讲解与配图是主体，代码示例少而短，练习只留一处轻量跟做；`以练为主` → 讲解只作引入，动手是主体；`讲练并重` → 讲一段立刻练一段。**不要写死比例**
6. **交稿前自检**：`<python> -X utf8 -B '<root>/scripts/render_lesson.py' '<subject_path>' '<节点id>' --check`（只解析校验、不写盘）。**题库/锚点类报错此时是预期的**（题还没出、「练习题库」还没写盘），别消它——尤其别补 `empty_reason`、别删 `::: quiz` 块；其余每一行都改到没有
7. 返回：「课件内容文件」路径、要点摘要（3-5 条）、每处锚点**想要的题型**（锚点文本在文件里，不用抄回来）

## 速查页（按需）

值得长期速查的知识点，写一份「速查页」（`<subject_path>/reference/` 下，自包含、引用共享层与组件），并在课件里链接它；不必每课都写。速查页是独立于课件的文件，不属于渲染器的输入。

## 渲染器负责的部分

这些由渲染器从内容文件产出，你交内容就行：

- **页面结构**：`head` 与共享层引用、顶栏与主题开关、页头 eyebrow（`序号 · 标题`）、提问提示、页脚、脚本引用
- **上下节课指针**：按「课程大纲」的 `nodes:` 顺序算
- **图注编号**：按页内出现顺序自动编号
- **图注的来源与许可**：按「图片库索引」那一行自动补
- **公式排版**：注入离线 KaTeX，你只管写 TeX：行内 `$…$`、块级 `$$…$$`
- **图注与页面的成品样式**：字体、间距、宽度都由容器定

**内容文件里只有内容格式。** 渲染器认不出的写法会带行号报错，不静默降级。

## 配图（本文件是配图规范的唯一 owner）

操作规程：

1. **先读「图片库索引」**，按主题标签找本章要讲的点；没有对应标签就别硬凑
2. **挑到就用**：图片路径逐字写 `../assets/img/pool/<文件>`
3. **挑不到就自己产**：**画法自己挑**；真实照片/界面这类只能采集的，交总控派 `image-scout`。别为配图拖住正文
4. **自己产的图要留三样东西**：图落「图片库」、脚本落「产图脚本」（`assets/img/gen/<同名>.py`）、「图片库索引」**追加**一行——`来源 URL` 写「本机生成（`assets/img/gen/<名字>.py`）」、`许可` 写「本项目自产」、`抓取日期` 写生成当天
5. **用图前先打开图片看一眼**（用宿主图片查看工具打开那个文件），画面和图注对不上就换图或不配；图注只写画面里真有的东西。

写图规矩：

- **图来自「图片库」或自己产**，只出现在 `::: figure` / `::: svg` 块里；**每张必须有 `alt:`**，`caption:` 只写一句话
- **别依赖外链**（页面里的图要能离线打开）；**单张 ≤500 KB**，超了先降 dpi
- 自己产的图**可以裁、缩、换配色**（"不改图"只约束采集来的图）；matplotlib **默认字体不出汉字**，脚本需指定 CJK 字体
- 自产图同样进「图片库」、登记进「图片库索引」；**索引的列与文件命名格式见 `image-scout`**
- **不许写死宽度**：`::: svg` 里只给 `viewBox`，显示宽度交给容器；觉得图太大就画小一点，别用上限压
- **字号比例有下限**：最小的 font-size ÷ viewBox 宽 ≥ 2%（栏宽 700px 时约 14px）。比例不够就调字号或调 viewBox

## 边界

- 只做当前节点；与 `objective` 无关的知识点先放一放，需要时记进"待学清单"交给总控
- 不碰课程与档案文件（「课程大纲」「学习进度」「科目使命」「资源清单」「术语表」「科目档案」「共享记忆」）——归总控
- 课件的**着眼点**要照顾到，**怎么讲、分节怎么写**按倾向与对这个学生的判断现场定
- 来源不足或全都不通时，在返回里说明缺什么并**报给总控补收集**（`resource-scout` 的活）；不自己另找清单外的站点

## 本地修改版的数据契约

本节与旧示例冲突时以本节为准。执行前读取 `<root>/docs/使用/本地修改版.md`。使用同一已验证 Python 3.10+ 环境并安装 requirements.txt。学习数据只写独立工作区；使用宿主会话 ID 作为稳定 session_id，所有断点命令传 --session-id 和 --subject，暂存只清理本会话的具体任务目录。

- 页面作答必须先导出，再由 learning_records.py import 归档。聊天回答也按相同题目身份/版本、首答时间和帮助字段留存。不能用“已读”“答对了”替代原文。
- 正式升级经 learning_records.py assess；只更新 covered_objectives 对应节点，附 criterion、原始作答或实际产物哈希。首答错、先看答案或有帮助的成功不能证明独立应用；旧状态保留且标记未核验。mastery 仅是 AI 建议值。
- 继续学习先查询 review_scheduler.py due。仅给关键知识点和真实错题建立 register 项，先独立回忆再四档评分，record 或普通 import 使用同一入口计算日期。未评分不调度，帮助练习不推进正式间隔，错误自评应为 Again。FSRS 到期不改变章节进度，迁移和应用能力仍按实际项目证据判断。
- 有教材文件夹或公开课程时先 source_index.py scan/fetch/search，引用 source_id/source_version/locator；原件只读，扫描 PDF 无文本应注明需 OCR，视频只使用现有字幕。
- 采用原课程时用 course_import.py 的 existing 模式，保持原 unit_id、顺序、章节粒度和作业；生成解释/题目注明补充，不强制 40 分钟拆章或自编实验。更新先审阅差异，不自行传 --accept-changes。
