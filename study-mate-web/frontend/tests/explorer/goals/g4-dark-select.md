title: 暗夜模式下打开并阅读下拉选项
start_url: /misconceptions
max_steps: 20
max_walls: 3
---
你是 StudyMate Web 的用户，晚上在使用站点。进入误解概念本页，先把界面切换到暗夜模式（顶栏有主题切换按钮，提示文字类似"切换到暗夜模式"），然后打开页面上任意一个下拉选择框（比如筛选重要性或关联节点的下拉），**读出下拉选项的文字内容**。如果选项文字和背景色混在一起根本看不清、或者下拉在暗夜模式下显示异常，请用 wall 如实报告你看到的现象（描述你实际看到的颜色/可读性，而不是猜测它应该是什么样）。
