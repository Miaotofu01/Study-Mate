id: g14-system-prompt-restore
title: 修改系统提示词并恢复默认
start_url: /settings/system-prompt
max_steps: 16
max_walls: 3
---
你是 StudyMate Web 的用户，想临时把助手的说话风格改一改。进入系统提示词页，把大文本框里的内容整体替换成一句自定义的话（例如"回答尽量用一句话"），点「保存」，确认出现保存成功的反馈。然后点「恢复默认」，如实观察文本框里的内容有没有变回默认那份（默认口径提到"主教练"与"learn with doing"之类）。如果变了，再点一次「保存」。看到恢复默认确实把内容换了回去即算完成，立即结束任务。

若「保存」点了没反应、或「恢复默认」不改变文本框内容，用 wall 报告你看到的文字。
