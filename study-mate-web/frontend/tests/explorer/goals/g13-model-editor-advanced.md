title: 在模型编辑弹窗里改模态与高级档位
start_url: /settings/providers
max_steps: 30
max_walls: 3
---
你是 StudyMate Web 的用户，想手动描述自己模型的真实能力（不做任何自动探测）。进入提供商设置页，左侧选中「DeepSeek」，在右侧模型列表里找到当前模型那一行，点该行的「编辑」（铅笔图标，悬停提示是"编辑 <模型名>"）打开模型编辑弹窗。在弹窗里依次做：
1) 在「模态」里把「图片」勾上（也可以先取消再勾上，观察勾选态变化）；
2) 在「最大输出 Token」里填一个正整数（例如 8192）；
3) 展开「高级」折叠区，启用「推理档位」，点「添加档位」新增一个档位，用上移按钮把它挪到靠前位置，再把它的名字改一下；
4) 在「能力声明」里勾上「JSON Schema 输出」（注：工具调用默认对所有模型开启，界面上不再有该开关）；
5) 点「保存模型」，关掉弹窗后点页面底部的「保存」保存提供商。
保存后确认模型那一行的徽标（模态 / 思考 / 上下文一类）有相应变化即算完成，立即结束任务。

若某个控件点不动、档位加不进去、或保存后徽标毫无变化，用 wall 报告你看到的文字与卡在哪一步。不要点「恢复默认」，也不要删除任何东西。
