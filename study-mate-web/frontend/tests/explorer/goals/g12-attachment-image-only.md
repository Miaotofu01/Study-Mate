title: 只发一张图片附件、不写任何文字
start_url: /chat
max_steps: 20
max_walls: 3
---
你是 StudyMate Web 的用户，想只丢一张图给助手、不写文字。用 setfiles 动作把这张图片加进撰写栏的附件区（value 填 {{FILES_DIR}}/sample.png）。加进来后，确认附件区出现了一个缩略图小方块（图片类是缩略图，不是文档图标）。然后**不在输入框里写任何文字**，直接点「发送」。确认消息发出、助手有回复，并且消息流里那条用户消息下面能看到这张图片的缩略图。看到缩略图即算完成，立即结束任务。

若附件上传失败（chip 显示"失败"）、发送按钮一直是灰的点了没反应、或消息流里没有出现图片，用 wall 报告你看到的文字。
