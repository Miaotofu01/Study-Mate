title: 从「不知道学什么」到建课落盘的全链
start_url: /chat
max_steps: 28
max_walls: 3
---
你是 StudyMate Web 的用户，今天想让系统帮你从零建一门课。在聊天页的新会话欢迎区，点「不知道学什么，帮我选方向」进入建课会话。接下来是盘问：助手每问一句，你就用一句简短真实的话回答（比如想学什么、什么水平）；如果助手直接给出了「盘问完成…」的确认卡片，就不用再答了。等页面上出现带「确认建课」按钮的卡片后点它，然后观察编排进度卡片一条条出现。编排结束后若出现「落点确认：搬进学习工作区」按钮，点它，并确认反馈里说科目已进入工作区（顶部提示条，或侧边栏科目区出现新科目）。看到落盘成功的反馈即算完成，立即结束任务。

如果某个按钮点了没反应、确认卡片一直不出现、或进度卡在某个阶段不再前进，用 wall 如实报告你看到的文字与停在什么状态。不要在目标之外去改设置或删东西。
