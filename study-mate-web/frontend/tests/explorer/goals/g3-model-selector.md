title: 打开模型选择器并切换模型
start_url: /chat
max_steps: 8
max_walls: 3
---
你是 StudyMate Web 的用户，想换一个模型试试。在聊天页**底部撰写栏**找到显示当前模型的按钮（当前显示 DeepSeek / deepseek-chat，悬停提示"切换当前使用的提供商 / 模型"），点开模型选择下拉，从列表中选择**任意一个**其它模型即可。操作过程中不要点到下拉框之外的任何控件。确认按钮显示已更新后，立即结束任务——不要继续切换其它模型。如果下拉打不开、选项点不动、或者切换后显示没变化，请用 wall 如实报告。
