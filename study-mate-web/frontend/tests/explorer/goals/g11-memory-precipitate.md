> **挂起（2026-10-04）**：聊天侧「沉淀记忆」入口已随右栏「会话关联」整段移除而**没有可执行路径**——本目标当前跑不通，勿据此判 wall。后端端点（`/api/memory/suggest` / `/confirm`）与 `MemoryDialog.tsx` 都保留；入口接回后去掉本段即可恢复。可替代的现存路径是课程页节点详情里「评估通过 → 沉淀记忆」。

你是 StudyMate Web 的用户，想让自己的一些习惯被长期记住。在聊天页右侧「会话关联」面板里把科目关联为 computer-networks，然后发一条消息（例如"我习惯先看例子再听讲解"），等助手回复完整显示。接着在右侧边栏点「沉淀记忆」。弹窗会列出几条建议：取消勾选其中一条，把保留的那条内容改一改（点进它的输入框编辑），再点底部的「写入记忆（N）」按钮。确认出现"已写入 N 条记忆"并给出 MEMORY.md 路径一类的反馈即算完成，立即结束任务。

若「沉淀记忆」一直是禁用状态、弹窗列不出建议、或写入点了没反应，用 wall 报告你看到的文字。
