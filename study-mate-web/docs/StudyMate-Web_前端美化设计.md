# StudyMate Web 前端美化设计规范与实施蓝图

> **文档定位**：本规范以工业级成熟参考实现 `DeepTutor/web` 为对标基准，紧密围绕 StudyMate Web 当前已落地的三大功能区域（Chat 对话伴学、课程图谱、概念本）以及核心特性（产课链、质检工单、长期记忆、学习工作区），制定系统化的前端视觉美化与组件布局升级方案。
>
> **核心原则**：
> 1. **视觉跃升，逻辑无损**：仅对视觉样式、组件布局、排版节奏与交互动效进行现代化重构，不破坏任何既有业务逻辑、数据接口与状态流转；
> 2. **严格保护 E2E 契约**：所有现存的 `data-testid`、核心可访问性语义及关键容器层级保持兼容，确保全量测试持续绿灯；
> 3. **分层分阶，平滑演进**：将改进拆解为 5 个独立验证的实施里程碑，便于阶段性评审与对照验收。

## 一、 设计理念与整体风格定义

### 1.1 现状痛点
当前的 `study-mate-web/frontend` 虽已实现完善的全链路学习闭环，但在视觉呈现上带有较强的“工程原型（Functional Prototype）”色彩：
* **单层画板感强**：主视口、侧边栏、卡片均依赖同一套 `--background` 底色与 1px 细硬线框，缺乏纵深光影与材质明度阶梯；
* **色彩压迫感重**：深绿品牌色（`#1c5a40` / `#2d7a58`）在用户气泡、按钮上直接使用大面积高饱和填充，与温和的米黄纸张底色（Paper `#f7f3ea`）形成过强对比；
* **排版缺少人文呼吸感**：字体纯走系统默认回退，标题与正文字阶跨度小，缺乏如学术讲义般典雅的衬线大标题节奏；
* **交互原语简陋**：依赖 `window.prompt`、`window.confirm` 进行重命名与删除，输入框为扁平横条而非现代 AI 工作台。

### 1.2 对标 DeepTutor 的美学演进目标
* **学术伴学工坊（Scholarly Atelier）**：融合自然暖调纸张质感与精密现代科技工具感。
* **呼吸式留白（Breathing Space）**：采用弹性边缘渐变溶蚀、统一内边距节奏（4px / 8px / 12px / 16px / 24px）。
* **轻盈高质感材质**：引入四级明度表面（Surfaces）、半透明微边框（`border-foreground/8`）、弥散微阴影（Ambient Shadow）与毛玻璃模糊（Backdrop Blur）。

## 二、 设计系统与材质层级（Design System & Tokens）

### 2.1 表面层级体系（Semantic Surfaces）

抛弃单一 `--background`，构建具备空间景深的语义层级：

| 语义层级 | CSS Token | 亮色模式（Paper 暖色系） | 暗色模式（Dark Obsidian） | 应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **L0 画布底色** | `--surface-canvas` | `#f8f6f0`（微透暖白底） | `#141816`（沉浸玄黑） | 网页最底层容器、主视口底层 |
| **L1 次级工作台** | `--surface-subtle` | `#f1eee5`（低反差暖灰） | `#1b211d`（深曜石） | 左侧导航栏、右侧工具栏、只读辅助区 |
| **L2 内容/卡片** | `--surface-card` | `#ffffff`（纯净高亮） | `#232b26`（次深石板） | 消息卡片、图谱节点卡、设置选项卡 |
| **L3 浮层与弹窗** | `--surface-raised` | `#ffffff` | `#2b342f` | 模态弹窗、Popover 气泡、下拉菜单 |
| **遮罩层** | `--overlay` | `rgba(28, 24, 22, 0.42)` | `rgba(0, 0, 0, 0.65)` | 弹窗背景蒙层、移动端抽屉遮罩 |

### 2.2 品牌色克制与提纯（Brand & Accents）
不再使用大面积刺眼实色块，改用微透明渐变与重点高亮：
* **Brand Primary**：
  * 亮色：`rgb(28 90 64)`（森林墨绿），用于关键图标高亮、选中项指示线、主要 CTA 按钮；
  * 暗色：`rgb(54 140 102)`（青翠玉绿），在暗底上具备极佳的可辨识度。
* **交互背景柔化**：
  * 选中/激活态：`color-mix(in srgb, var(--brand) 10%, transparent)` 作为淡绿高光底；
  * 边框微光：`color-mix(in srgb, var(--brand) 35%, var(--border))` 配合聚焦光环 `ring-2 ring-brand/30`。

### 2.3 字体体系与排版节奏（Typography）

#### 字体栈（Font Family Stack）
```css
/* tailwind.config.ts 扩展 */

  sans: [

    'PingFang SC',
    'Hiragino Sans GB',

    'Noto Sans SC',
    'system-ui',
    'sans-serif',
  ],
  serif: [
    'var(--font-serif)',
    'Songti SC',
    'STSong',
    'Noto Serif SC',
    'Source Han Serif SC',
    'Georgia',
    'serif',
  ],
  mono: [
    'JetBrains Mono',
    'Fira Code',
    'ui-monospace',
    'monospace',

```

#### 字阶与节奏
* **Hero 问候语/主标题**：`font-serif text-3xl sm:text-4xl font-medium tracking-tight text-foreground`；
* **模块大纲/标题**：`font-serif text-lg font-semibold` 搭配温和图标；
* **正文/Markdown**：`font-sans text-[14.5px] leading-[1.72]`，中文字符间距微调，行高更适合长篇深度学习；
* **代码与标注**：`font-mono text-[12.5px]`。

## 三、 全局导航与框架升级（AppShell & Nav Rail）

### 3.1 侧边栏双态演进（60px Rail vs 展开抽屉）
目前侧边栏只支持宽度的连续拖拽（180–420px），无法完全收纳。对标 `DeepTutor/web/components/sidebar/SidebarShell.tsx`：

```
[折叠态 60px 极简 Rail]                [展开态 240px 完整侧栏]
+---+----------------------------+    +----------------------------+
|   | (Logo / 悬停展开按钮)       |    | [Logo] StudyMate   [收起图标]|
|   +----------------------------+    +----------------------------+
|   | [Chat 图标] (Tooltip)      |    | [Chat]   对话伴学          |
|   | [图谱图标]   (Tooltip)      |    | [图谱]   课程图谱          |
|   | [概念本图标] (Tooltip)      |    | [概念本] 概念本            |
|   +----------------------------+    +----------------------------+
|   | --- 分割线 ---              |    | 会话列表 (按最新时间排布)    |
|   | [新对话 +]                 |    | + 新对话                    |
|   |                            |    | 科目大纲列表                |
|   +----------------------------+    +----------------------------+
|   | [主题]  [设置]             |    | [主题切换]  [设置]         |
+---+----------------------------+    +----------------------------+
```

* **收起/展开交互**：
  * 顶部 Logo 区：正常展示 StudyMate 绿叶 Logo，鼠标悬停时平滑渐变为 `PanelLeftOpen` / `PanelLeftClose` 图标；
  * 收起态（Collapsed）：导航项与底栏操作仅展示 18px 图标，外置 `Radix UI` / CSS Tooltip（右侧浮出展示标题与快捷键）；
  * 展开态（Expanded）：保留现有的右侧拖拽调宽手柄（180–420px 并持久化到 `localStorage`）。

### 3.2 交互原语升级：告别原生弹窗
* **会话/科目重命名**：
  * 双击标题或点击小笔图标，直接原位切换为内联输入框（`<input autoFocus onBlur={save} onKeyDown={handleKey} />`），按 Enter 确认，按 Esc 取消；
* **删除确认**：
  * 点击垃圾桶后弹出气泡微确认（Popover：“确定删除该会话？” 带“取消 / 确认删除”按钮），禁止触发浏览器底层的 `window.confirm`。

### 3.3 移动端与窄屏响应式（<768px）
* 引入 `AppShell` 响应式逻辑：在 `<768px` 宽度下，侧边栏脱离普通 Flex 文档流，转为绝对定位抽屉（Fixed Drawer），配备 40% 黑色遮罩与平滑滑入动画；
* 顶部挂载移动端小顶栏（44px），包含菜单汉堡按钮与当前页面标题。

## 四、 聊天主视口与工作台输入框（Chat & Composer）

### 4.1 输入工作台（Workbench Composer）重构

当前横条输入框改造为上下结构的独立圆角卡片（`rounded-3xl border border-border bg-surface-card shadow-sm`）：

```
+--------------------------------------------------------------------------+
|  [附件预览胶囊区: 紧凑排列在文本框内上方，支持点击预览/快捷移除]               |
|                                                                          |
|  输入框 (textarea 自适应高度，支持多行舒畅排版，占位符带有学习引导)       |
|                                                                          |
|--------------------------------------------------------------------------|
|  [📎 附件]  [🧠 探索建课]  [⚡ 快捷指令]  |  [模型选择胶囊: mimo v2.6] [↑ 发送]|
+--------------------------------------------------------------------------+
```

* **布局与分层**：
  * **上层**：多行自动伸缩输入区（`min-h-[44px] max-h-[220px]`），滚动条采用悬浮极细样式；
  * **下层工具条（Toolbar）**：
    * 左侧操作组：回形针附件图标、建课探索快捷按钮、提问预设菜单；
    * 右侧操作组：精致的模型/推理档位选择胶囊（点击呼出下拉面板）、发送/停止圆形按钮。
* **CSS 容器查询（Container Queries）**：
  * 在 `@container (max-width: 580px)` 时，模型选择胶囊自动将文字折叠为小芯片图标，防止工具栏折行拥挤。

### 4.2 消息流（Message Stream）视觉与排版升级

#### 1. 视口边缘“淡出遮罩”（Edge Fade Masking）
在聊天消息滚动容器中使用渐变遮罩：
```css
mask-image: linear-gradient(to bottom, transparent 0px, #000 24px, #000 calc(100% - 40px), transparent 100%);
```
长对话滚动时，顶部和底部文字柔和“溶蚀”于视口边缘，消除文字生硬切断的割裂感。

#### 2. 用户与助手消息对齐质感
* **用户消息气泡**：
  * 放弃高饱和墨绿色块（白字），改用柔和的次级雅白底色（`bg-[var(--surface-subtle)] text-foreground border border-border`），或带有 10% 品牌微绿的现代微光气泡；
  * 代码块在气泡内部保证深色背景（`#1f2421`）与高亮语法高反差。
* **助手消息结构**：
  * 头像采用轻巧的立体扁平 Logo 微徽章；
  * 正在思考时展示带有柔和脉冲呼吸动效的 **思考折叠卡片（Thinking Accordion）**；
  * 生成过程中在文本末尾附带跳动呼吸光标（Blinking Pulse Indicator）；
  * 消息底部悬停浮出微型工具槽：一键复制代码、重新生成、提取入概念本（`NotebookPen`）、展开质检/事件详情。

#### 3. 产课链消息卡片（KindMessageCard）质感升级
* 阶段推进卡片（Stage/Handoff/Done）：从纯单线框改为带有左侧粗色条的优雅步骤卡；
* 质检打回与工单入口：配备专属警告与调试小徽章，明确引导点击工单处理。

## 五、 课程图谱与节点详情侧栏（Course Graph & Node Detail）

### 5.1 图谱画布空间感与节点卡片化
* **点阵背景（Dot Matrix Background）**：
  画布底层注入 20px 间距的微弱点阵背景图案（`radial-gradient(#d1ccc0 1px, transparent 1px)`），赋予类似 Figma / Miro 的无限白板专业生产力工具质感。
* **Cytoscape 节点现代化样式**：
  * 节点外形从简单的纯色矩形升级为**现代知识胶囊**：微圆角、柔和边框阴影、双行排版（节点序号小标 + 知识点标题）；
  * **状态表达（Status Presentation）**：
    * 不再用全屏高饱和色块涂满，改用卡片左边缘状态胶囊点或底部掌握度光条；
    * 选中节点：外圈扩散出带透明度的品牌色光晕脉冲（`overlay-color: brand; overlay-padding: 8px`）；
  * 连线美化：贝塞尔平滑曲线，灰色调采用中性柔和灰，箭头比例微调。

### 5.2 节点详情侧栏（NodeDetail）卡片式重组
* **模块化区域**：
  1. **标题与掌握度大卡片**：展示当前状态指示灯、掌握度等级百分比环形进度条；
  2. **状态推进按钮组**：胶囊形式排布下一阶段建议状态（“学习中”、“初步理解”、“能独立应用”）；
  3. **前置依赖与后置关联**：以点击可跳转的标签云呈现；
  4. **行动 CTA 按钮**：
     * “进入本节课件”（带 `ArrowRight` 图标的主要绿色卡片）；
     * “针对本节点提问 / 练习”（快速唤醒 Chat 对话）；
     * 质检工单入口条（若存在打回质检工单，浮动高亮显示）。

## 六、 课件阅读与沉浸式测验面板（Lesson & Grading Panel）

### 6.1 沉浸式测验面板（GradingPanel）工作台重构
当前单列向下平铺所有题目的设计使长题量体验沉重。全面对标 DeepTutor `QuizViewer` 的设计理念：

```
+--------------------------------------------------------------------------+
| 判分面板               [1]  (2)  [3]  [4]  [5]            [< 上一题] [下一题 >] |
| 掌握进度 [===========>                    ] 40%                     [收窄/全屏]|
+--------------------------------------------------------------------------+
| Q2. 简答题 · 难度: 中等                                                    |
|                                                                          |
| 题目正文 (支持富文本代码与公式)                                              |
| 假设我们正在编写一个异步事件总线，请说明为什么消费端必须显式处理异常？          |
|                                                                          |
| 作答区:                                                                   |
| +----------------------------------------------------------------------+ |
| | [你的回答输入框 / 代码编辑区...]                                      | |
| +----------------------------------------------------------------------+ |
|                                                                          |
| [提交并判分] (若已判分，下方展开带颜色反馈的判分卡片与 AI 解析)             |
+--------------------------------------------------------------------------+
```

* **题号导航条（Question Chips Bar）**：
  * 顶部展示题号胶囊圆形序列（1, 2, 3...）；
  * 状态色一目了然：未做（灰色）、已输入未提交（淡蓝）、正确（翠绿）、需巩固/错误（珊瑚橙）；
  * 支持点击题号直接切题，并配有上一题/下一题快捷翻页与顶部进度指示线；
* **单题聚焦呈现**：
  * 每次主视口聚焦于一题，降低认知负荷；
  * 已判分题目在下方平滑展开“标准答案对比”、“判分理由”与“记忆提炼建议”；
* **保留批量模式开关**：提供“单题聚焦”与“全部平铺”视图切换，照顾习惯快速浏览的用户。

## 七、 设置中心与提供商管理（Settings & Providers Workspace）

  * 当页面检测到未保存改动（`dirty: true`）时，从页面底部平滑升起悬浮操作栏：“检测到未保存的提供商修改 [放弃更改] [保存设置]”，避免用户忘记点击保存或找不到保存按钮。

* 表单分节卡片化（Card Sections）：
  1. **基本标识**：模型 ID、显示名称、模型说明；
  2. **容量参数**：上下文窗口（Context Window）、最大输出 Tokens（分栏数字输入，配万/K 单位快捷胶囊）；
  3. **模态与能力**：多模态复选胶囊组（文本、视觉、音频、工具调用）；
  4. **深度思考/推理（Reasoning）**：独立开关面板，开启后展开推理档位标签（如 `low` / `medium` / `high`），支持点击添加/移除自定义档位。

## 八、 浮层、模态弹窗与微交互（Modals & Micro-interactions）

### 8.1 弹窗与抽屉质感统规
* **模态遮罩（Backdrop Scrim）**：
  * 全局统一采用 `backdrop-blur-sm bg-black/45`，背景产生电影感高斯模糊，让用户视线瞬间聚焦于中央弹窗；
* **弹窗容器**：
  * 外框圆角统一为 `rounded-2xl` 至 `rounded-3xl`（16px–24px）；
  * 边框采用细微发光线 `border border-border/80 shadow-2xl`；
* **记忆沉淀面板（MemoryDialog）**：
  * 提炼出来的各条记忆以独立可拖拽卡片展示；
  * 分节选择框与文本编辑框从粗糙默认边框重构为沉浸式无边框微底色卡片；
